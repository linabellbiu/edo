# Kubernetes 监控状态提示验收

范围：集群总览缺少节点指标时的提示；只读查询当前监控组件，不更改安装器或集群资源。

| ID | 角色与前置 | 操作 | 预期 |
| --- | --- | --- | --- |
| KM-01 | 可读节点与 kube-system 工作负载；当前 Metrics Server 尚未就绪 | 打开总览 | 提示监控组件正在安装或启动，缺失用量保持空值 |
| KM-02 | 同上；当前 Pod 明确报告镜像拉取超时或失败 | 打开总览 | 分别提示超时或失败；不暴露原始错误、地址或配置 |
| KM-03 | 节点 Metrics API 返回 403 | 打开总览 | 显示指标读取权限不足，不显示安装中 |
| KM-04 | 仅节点读取权限，或不能读取 kube-system | 打开总览 | 不越权探测工作负载，保留安全的暂不可用提示 |
| KM-05 | 当前版本健康，旧副本 Pod 拉取失败 | 打开总览 | 旧 Pod 不影响当前状态；已就绪但无采样时提示等待指标 |
| KM-06 | 从缺测恢复有效采样 | 刷新总览 | 提示消失，真实用量恢复；不改变历史安装任务结果 |
| KM-07 | 浅色、深色及 390px 预览 | 切换状态及主题 | 单行区域内自然换行，文字和图标清晰，无横向溢出 |
| KM-08 | 组件诊断期间项目或命名空间权限被撤销 | 请求总览 | 拒绝返回旧授权范围的统计及监控状态 |

启动和拉取故障用隔离 API/页面夹具验证，不通过破坏或重装真实集群制造故障。

2026-11-14 验证：KM-01～06、08 的状态与权限分支通过隔离 API 和组件回归；KM-07 通过真实页面夹具的浅色桌面、深色 390px 截图验收。页面已核对启动、超时、拉取失败、权限和恢复状态；未用故障夹具冒充真实集群安装验收。
