# EDO 列表可见范围验收

2026-11-05，针对 BT-04（公共权限）和 BT-07（应用与流水线）的列表缺失问题回归。本次不启动业务流水线、构建或部署，也不修改现有业务资源。

## 规则与修复

列表展示当前用户在所选项目内有有效查看权限的对应资源，不以创建者或启用状态隐式过滤。后端继续核对项目成员、角色及个人显式拒绝；项目权限不授权平台管理。个人凭据、密钥内容和其他明确的所有权边界保留。

原流水线页面只把共用方案作为表格数据，实际应用流水线未进入列表。新增 `GET /api/v1/workflows`，使用 `workflow.read` 和项目范围统一查询两类资源。页面区分归属、关联应用与流程规模，操作使用准确类型及 UUID。只拥有流水线查看权限时，列表与编辑器的只读内容不依赖完整应用列表权限。

列表读取不创建或运行任务，不调整数据库结构。切换项目、撤权及离开页面会取消读取并清空旧范围数据；迟到响应不能回填。
