## 实现与复用

- 全屏复用已安装的 Ant Design Vue Modal、Vue Teleport 和 CodeMirror。同一编辑器 DOM 在内联区与对话框之间移动，保留语法检查、只读、选择和撤销；没有引入第二套编辑器或新依赖。
- 文件来源使用现有 Collapse、Radio、Tooltip 和按钮，参考用户提供的 Gitee 带框分区布局；保持 EDO 的主题、权限及项目范围。
- 只移除专用变量和 Docker/dockercompose 目录的表单入口，不删除兼容字段、已存数据或运行能力。新多镜像方案的内部目录在运行快照中固定，旧方案的显式目录继续沿用。
- 新目录解析只调用现有受控主机执行器读取固定的 HOME 表达式，限时 5 秒、输出最多保留 1024 字节；校验绝对路径、规范化和控制字符。后台失败记录操作、主机、目标与原始错误，不回传网络或脚本文本。
- 只有运行快照增加可省略的自动目录标记，没有数据库列或迁移变更。
