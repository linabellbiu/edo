# Kubernetes 通用部署方案与阶段覆盖

Kubernetes 部署方案本身就是用户可配置的通用模板，直接展示工作负载、服务与网络、启动与发布、健康检查等配置，不再提供额外的“部署模板”选择。通用部署方案保存可复用的默认规则。流水线部署阶段选择方案，绑定自己的集群、命名空间、Deployment、容器及上游镜像，并可调整本阶段配置。修改阶段不修改共享方案；“修改方案”入口编辑方案库，“恢复参数默认”只移除参数差异，保留本阶段目标与镜像绑定。

阶段仅保存字段差异。显式 false、空参数数组和删除可选探针分别保留；端口数组整体替换。未覆盖字段继续继承方案的后续默认配置，新运行固定最终配置与来源方案，已生成的运行不重新合并当前方案。执行身份和目标按任务隔离；同一方案供多个任务使用时不能串改参数或实例。固定方案已发布的目标，仅调整参数时保持原实例身份，内部环境审批和变量范围继续生效。

新增阶段覆盖复用现有 `gopkg.in/evanphx/json-patch.v4` 的 RFC 7396 实现，配合模型字段白名单及最终配置校验；不增加新依赖或组件。工作负载、网络、集群目标与上游镜像继续检查当前权限、项目范围和准确身份。已保存开启网络的阶段在撤权后直接删除覆盖或切换来源，同样不能绕过网络修改权限。

本批提供的常用参数：

| 分区 | 可配置内容 | 未设置时 |
| --- | --- | --- |
| 目标 | 集群、命名空间、Deployment、容器、上游镜像 | 应用名与选定镜像补空字段，集群需明确选择 |
| 工作负载 | 副本、CPU/内存申请和限制 | 沿用方案默认 |
| 服务与网络 | HTTP/TCP 服务端口、容器端口、NodePort | 默认全部关闭 |
| 启动与发布 | 命令和参数数组、容器工作目录、镜像拉取策略、终止宽限期、滚动或重建策略、额外/不可用副本 | 沿用镜像与 Kubernetes 默认 |
| 健康检查 | readiness、liveness、startup 的 HTTP/TCP 检测和等待/间隔/超时/失败阈值 | 默认关闭 |
| 执行 | 部署超时 | 沿用方案默认 |

后续优先补充已有 ConfigMap/Secret 的环境变量或文件引用、PVC 挂载；再按需要提供节点标签与容忍、Ingress、ServiceAccount。它们需要各自的资源选择、权限和校验，不在本批放置尚未接入执行器的输入框。当前没有自动增加 hostPath、宿主机网络或外部负载均衡。

| ID | 前置与角色 | 操作与预期 |
| --- | --- | --- |
| KP-01 | 有流水线与工作负载修改权限；通用 K8s 方案 | 选择方案并绑定目标，保存重开保持方案关联及目标；参数来自方案 |
| KP-02 | 同上 | 本阶段修改副本、资源、探针和超时，仅保存差异，共享方案不变 |
| KP-03 | 已有覆盖 | 恢复默认保留目标；未覆盖字段继承方案更新，已有运行快照不变 |
| KP-04 | 两任务引用同一通用方案 | 不同目标和覆盖独立；重复目标阻断 |
| KP-05 | 已部署的固定方案 | 仅修改副本或超时不更换实例身份；回退核验准确目标 |
| KP-06 | 网络权限撤销或个人拒绝 | 开关、直接删除覆盖、切换来源及共享方案恢复默认均不能绕过权限 |
| KP-07 | 有上游构建关联 | 上游任务选择与清除含义准确，不能引用并行/后续阶段或他项目产物 |
| KP-08 | 独立合成浏览器 | 切换来源保留草稿，浅色/深色/390px、键盘和错误提示正常 |
| KP-09 | 本地已登录页面 | 独立窗口确认通用方案与高级参数入口，不保存业务配置或执行部署，保护原未发布草稿 |

Kubernetes API fixture 及数据库集成回归不冒充真实集群部署验收。
