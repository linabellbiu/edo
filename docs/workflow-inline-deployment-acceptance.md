# EDO 流水线自定义部署方案验收

部署任务提供“自定义方案 / 选择部署方案”。自定义方案复用现有部署编辑表单，选择环境和执行方式后写入当前任务的 `inline_deployment_plan`，只有保存流水线才持久化，不调用部署方案库写接口，也不向方案库或发布目标表创建记录。既有方案仍按 UUID 引用、校验状态和读取权限。

业务配置、校验和权限沿用现有实现，没有新增第三方依赖或数据库列。自定义方案在运行时只读解析当前环境的唯一执行主机或指定集群，固定完整执行快照；方案和目标的运行身份由流水线 UUID 与任务 ID 确定，保证后续发布更新原实例，复制到另一流水线后隔离。回退会重新核对当前流水线中的自定义目标，目标变更或来源移除后拒绝回退原位置。文件来源、变量及部署脚本同时支持自定义和引用方案。

重新打开部署任务时按已有定义或方案 UUID 回显来源。库方案的名称和配置默认只读，“更换”解锁方案选择，“修改”直接跳转到该方案的编辑抽屉并检查方案修改权限。两种来源在本次编辑中分别保留草稿；同值来源事件不清空关联或产生修改。停用、不可读或已不存在的原方案仍保留关联并提示，不以其他方案替代。流水线自身的文件来源和部署脚本继续在当前任务编辑。

## 用例

| ID | 前置与角色 | 操作 | 预期 |
| --- | --- | --- | --- |
| WF-INLINE-01 | 可编辑流水线、可查看环境；有上游构建 | 创建自定义方案，选择环境和方式，保存草稿后重新打开 | 自定义定义随流水线保存并回显，方案和目标表记录数不变 |
| WF-INLINE-02 | 已有可用部署方案 | 切换至选择方案，再切回自定义 | 库方案仍可选择；两种来源互斥，本次编辑会话保留自定义草稿 |
| WF-INLINE-03 | 五种部署方式的独立测试数据 | 启用流水线并生成运行，修改草稿或复制到另一流水线 | Docker、单服务/多服务 Compose、主机脚本、Kubernetes 正确固定快照；旧运行不受草稿影响，跨流水线身份不同 |
| WF-INLINE-04 | 自定义方案或旧的库方案 | 尝试混合来源、伪造目标归属、无权限提交或切项目后继续提交 | 拒绝来源冲突，不保存客户端资源身份；权限与项目守卫有效，迟到回调不能写错目标 |
| WF-INLINE-05 | 已发布实例的独立 Kubernetes 模拟 API | 预检回退，再修改当前自定义方案目标并再次预检 | 无方案库记录也能核对原发布归属；目标变化后禁止回退，预检没有外部写入 |
| WF-INLINE-06 | 桌面、窄屏和深色主题 | 打开任务、创建或编辑自定义方案、选择旧方案 | 两条入口明确，当前页面编辑，表单及任务配置可读 |
| WF-INLINE-07 | 已关联库方案的流水线；可编辑流水线和方案 | 读取后打开任务、重开任务、切换来源再切回、点击更换 | 选中“选择部署方案”，原名称和配置回显且默认只读；切换恢复原关联，更换只解锁选择 |
| WF-INLINE-08 | 同上；有多条方案 | 点击“修改”，关闭抽屉后刷新方案列表 | 精确打开关联方案，环境和配置正确；保留定位参数，消费编辑参数，不重复打开，不自动保存 |
| WF-INLINE-09 | 停用、丢失方案或缺少查看/修改权限；切换项目 | 打开部署任务、尝试修改链接 | 保留原关联，停用名称仍可见，不泄漏不可读名称；拒绝越权修改和跨范围打开，不打开其他方案 |

## 验证结果

WF-INLINE-01 至 06 均通过本地相应用例：五种方式的保存、快照、资源零新增、身份隔离及旧运行不变由真实独立数据库验证；正常 HTTP 保存接口通过；现有流水线及部署模块完整竞争检测通过；来源切换、无方案库创建权限的自定义保存及撤权守卫有交互回归。前端完整 1735 项、Vue 类型检查与构建、Go 静态检查与构建、Mage 测试通过。最后消除服务含锁浅拷贝后，相关快照与静态检查另行回归通过。

实际组件的本地页面已验证创建、保存、重新加载、已有方案选择、切回自定义草稿、编辑回显及深色 390 × 844 窄屏；抽屉宽度与内容宽度均为 390px，无页面横向溢出、脚本错误及方案库写请求。截图在本机 `/private/tmp/edo-inline-deploy-form.png`、`/private/tmp/edo-inline-deploy-panel.png`、`/private/tmp/edo-inline-deploy-dark-mobile.png`。验收浏览器与服务已关闭。

真实生产环境没有执行业务流水线或容器动作；本批只修改与提交代码，不推送或部署。后续部署脚本和文件来源调整另批交付。
