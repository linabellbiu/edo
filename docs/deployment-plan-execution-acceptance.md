# 部署方案执行配置验收

通知属于流水线任务。共享变量、镜像 Tag、dockercompose 项目与服务范围、文件来源、部署脚本和制品来源归部署方案保存；自定义方案随流水线保存，库方案独立保存。已有任务参数在方案未接管前继续有效，不修改历史运行。

| ID | 角色与前置 | 操作 | 预期 | 状态 |
| --- | --- | --- | --- | --- |
| PLAN-CFG-01 | 可修改流水线，已有部署任务 | 打开部署与通知分区 | 部署分区只展示方案；通知分区只保留通知 | 通过：真实组件页面 |
| PLAN-CFG-02 | 可创建、修改部署方案 | 配置文件来源、共享变量、Tag、脚本并保存重开 | 所有参数保存在同一方案，字段完整回显；Shell 自动检查 | 通过：页面保存、SQLite/MySQL HTTP |
| PLAN-CFG-03 | 流水线引用库方案 | 查看方案，点击修改，保存后返回 | 参数只读；修改入口指向准确方案；原任务配置可带入，通知不被带入 | 通过：页面只读、精确跳转与旧配置交接 |
| PLAN-CFG-04 | 可编辑自定义方案 | 编辑、切换方式、取消、保存 | 草稿按方式隔离；取消不修改任务，保存进入 inline_deployment_plan.execution_config | 通过：页面编辑、取消、切换草稿与自动保存 |
| PLAN-CFG-05 | 只读、撤权或切换项目 | 查看与尝试旧编辑回调 | 不提交写入；旧异步结果不跨身份回填；独立方案检查不要求流水线修改权限 | 通过：公共权限回归、组件撤权及范围检查 |
| PLAN-CFG-06 | 引用方案的应用流水线 | 创建运行，再修改方案 | 当前运行冻结原值；后续运行采用方案值；任务旧参数不能覆盖方案 | 通过：SQLite/MySQL 不可变运行快照 |
| PLAN-CFG-07 | 旧方案与旧任务配置 | 未迁移运行、显式迁入方案、明确清空 | 未迁移配置继续有效；迁入后方案统一管理；空对象明确清空，不复活旧任务值 | 通过：页面迁入、空对象清空与旧客户端保留 |
| PLAN-CFG-08 | 方案引用上游构建方案 | 使用不同任务 UUID、缺少构建、多候选或同阶段构建 | 唯一前序任务可解析；其他情况明确拒绝，不任取制品 | 通过：规则与真实数据库快照回归 |
| PLAN-CFG-09 | 隔离 SQLite、PostgreSQL、MySQL 数据库 | 新建、旧表升级、重跑迁移、继续写入 | 新列与数据正常，原 UUID、自增 ID、方案和流水线关联保持 | 通过：三种数据库真实迁移及继续写入 |
| PLAN-CFG-10 | 本地合成页面 | 浅色、深色、窄屏、方案预览与编辑 | 原布局、全屏 YAML、来源卡片、禁用与键盘交互可用 | 通过：页面、深色 390px、无横向溢出；全屏复用原验收 |

复用现有 Vue、Ant Design Vue、CodeMirror、GORM JSON 序列化和后端 Shell 解析器，不增加依赖。方案内上游来源引用构建方案，在运行启动时绑定当前流水线前序阶段的唯一任务，不能保存另一个流水线的任务作为新来源。
