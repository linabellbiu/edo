# EDO 配置历史与高亮对比验收

本次复用 `delivery_variable_revisions` 的持久化记录，不新增数据库表，不改部署版本生效规则。配置名称与生成文件相对路径独立，文件名不限定为 `.prod.env`。

编辑配置时以打开编辑器的保存版本为基线，实时标出新增与删除；历史入口显示版本、时间和修改人，可选择两个版本对比或查看单个版本。历史正文只读，不会自动保存、恢复或触发部署。

密钥的历史元数据不含正文和密文。普通读取会隐藏所有受保护版本；配置从普通内容改为密钥后，之前的版本也需要独立的 `delivery_variable.reveal` 权限。正文读取需要用户显式操作，后台记录项目、配置 UUID、版本及结果，不记录正文；响应禁止缓存。关闭抽屉、切项目或撤权会清理前端已读取内容并取消请求。

## 依赖选型

使用与已有编辑器同生态的官方 `@codemirror/merge` 6.12.3（MIT），复用现有 state/view/language 依赖，只增加一个包；npm 元数据的维护时间为 2026-10-19，解包大小 183623 字节。官方实现提供有界差异计算、删除部件和增量更新，不自行实现文本差异算法；只通过现有编辑器的可选属性接入，可单独替换。前端代码跨 Linux/macOS 构建且不增加常驻组件。npm 官方生产依赖审计报告为 0 条已知漏洞；镜像源没有公告接口，审计明确使用 npm 官方源。

## 固定用例

| ID | 前置与角色 | 操作 | 预期 |
| --- | --- | --- | --- |
| CFG-HIST-01 | 可编辑普通配置，已有多个版本 | 编辑正文、切换高亮并保存，再打开历史 | 原文作为基线，增删分别高亮，保存产生新版本且保留旧版本 |
| CFG-HIST-02 | 有配置查看权限 | 打开历史、加载更早版本、选择比较版本或相同版本 | 先读有界元数据；正文按需读取；历史只读；选择变化清理旧结果，空正文可查看 |
| CFG-HIST-03 | 有配置查看权限，没有读取正文权限 | 打开密钥历史或编辑密钥 | 不自动解密；不能读取原文，仍可提交新的替换内容 |
| CFG-HIST-04 | 独立读取正文权限 | 读取指定密钥版本并对比；再撤权、切项目或关闭 | 请求固定项目与版本；成功/拒绝有安全审计；内容清理、在途取消、迟到响应不回填 |
| CFG-HIST-05 | 不同项目或已删除配置；独立测试数据 | 按旧 UUID/版本读取、传入非法分页；模拟隐藏响应及失败 | 不泄漏正文或其他项目版本，不把失败当空文件；公开旧版本在配置加密后同样受保护 |
| CFG-HIST-06 | 桌面及窄屏，深浅主题 | 用键盘选择版本，查看差异及长行 | 控件可达、历史只读、高亮可读、页面无横向溢出 |
