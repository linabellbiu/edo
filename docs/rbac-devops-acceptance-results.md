# EDO DevOps RBAC 验收记录

本记录对应 [验收计划](rbac-devops-acceptance-plan.md)。本轮仅操作独立本地 EDO，不部署远程服务器，不接管同时进行的 NAS/K3s 安装。

## 已确认并修复的缺陷

1. **无法配置完整项目权限。** 目录有 115 项项目动作，角色及个人授权请求却最多接受 100 项。动作集合改为有界的 512 项，角色个数仍限制 100；未知权限、过量请求和越权委派仍拒绝，失败不部分写入。
2. **环境审核人不检查实际审批资格。** 旧版可把只有项目读取权限的成员设为必需审核人。候选列表与保存事务都复用当前项目授权计算，角色撤权、个人拒绝、成员移除、停用及部门变化都会影响资格。
3. **内置开发角色可关闭审批保护。** 真实普通账号在专属项目成功停用保护，取证后已恢复。固定 UUID 的开发模板只保留安全读取与明确列出的开发动作；初始化及新建项目时收敛旧模板，保留 UUID、成员关系和自定义角色。运维、审批、保护配置、密钥管理需要另行显式授权。
4. **部分长连接和 SQL 后台任务信任旧策略。** Casbin 允许后增加当前数据库项目权限复核。状态通知按每类资源重新过滤；SQL 检查、执行和审核同时核对动作及必要读取权限，保留冻结项目、授权人和禁止自审规则。
5. **MySQL 初始化不幂等。** 真实 MySQL 测试发现数据库排序规则与 Go 字节排序不同，同一权限集合被误判为变化并重建权限行。比较前使用一致的字节序，保留稳定行号断言。
6. **停用账号的休眠会话复活。** 真实在线请求及双 Cookie HTTP 回归均复现。停用状态与认证版本递增现在使用同一条条件更新；重新启用不恢复旧认证版本，重复启停保持幂等，新登录继续正常。
7. **内置 Docker 端点绕过主机项目范围。** 没有本地主机的项目仍能请求容器列表，真实请求返回 200，但当时隔离 daemon 为空，未读取其他项目容器内容。内置端点现在必须先核验当前项目可见且启用的真实本地主机；查找、连接、日志、终端、文件和改名均在访问 daemon 或写入前拒绝。独立路由回归同时验证原所属项目正常读取、越权请求的 daemon/日志/Exec 调用为零；不可见日志返回 404，真实 Docker 故障仍返回安全的 502。
8. **助手子工具信任旧资源动作。** 基础助手权限仍在而资源动作被撤销时，旧 Casbin 允许可继续读取项目记录或确认写操作。统一子工具授权追加当前数据库项目复核，覆盖原生工具、确认与输出；已通过 SQLite/MySQL 回归和本地模拟模型协议的 HTTP/SSE 红绿测试。尚未重载此修复，不代表真实模型 Key 联调。

新增回归覆盖正常允许、越权拒绝、存储失败、事务回滚和撤权；没有添加依赖或修改数据库结构。

## 尚待完成

- 以正常 Go 后端及前端项目，完成同一条真实 Docker 流水线、双人审批、应用可访问与岗位 UI/接口越权验收；这是当前最高优先级。
- 独立项目目前可读取内置 Docker 端点，但没有可选主机；正在核实正常配置入口及项目隔离边界。
- 助手修复尚待后续协调窗口重载；当前 Docker 真实任务期间不切换 API。
- 实际外部 SQL、Kubernetes、SSH、终端和文件传输须有专属明确目标；没有目标的项目保留“前置未满足”。
