# Kubernetes 局部授权拒绝验收

| ID | 角色与前置 | 操作 | 预期 |
| --- | --- | --- | --- |
| KA-01 | 已登录；集群命名空间/资源接口明确返回集群授权拒绝 | 连续读取并提交一次被拒操作 | 保留局部 403 及页面提示，不触发全站权限核验，不自动重放 |
| KA-02 | 当前项目权限已变化，或接口返回未知 403 | 请求业务接口 | 继续暂停旧权限并核验，不放宽全局鉴权 |
| KA-03 | 用户切换项目后旧请求返回 403 | 读取旧请求结果 | 丢弃旧响应，不影响新项目授权 |
| KA-04 | 本地页面持续收到集群授权拒绝 | 观察当前工作负载页面和侧栏 | 内容及菜单稳定，错误局限于对应集群范围，不形成请求循环 |

集群资源级授权与当前 EDO 项目授权分别处理；集群拒绝仍由服务端执行并向用户展示，不能为解决闪烁隐藏错误或授予权限。
