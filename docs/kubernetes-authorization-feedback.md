# Kubernetes 局部授权拒绝验收

| ID | 角色与前置 | 操作 | 预期 |
| --- | --- | --- | --- |
| KA-01 | 已登录；集群命名空间/资源接口明确返回集群授权拒绝 | 连续读取并提交一次被拒操作 | 保留局部 403 及页面提示，不触发全站权限核验，不自动重放 |
| KA-02 | 当前项目权限已变化，或接口返回未知 403 | 请求业务接口 | 继续暂停旧权限并核验，不放宽全局鉴权 |
| KA-03 | 用户切换项目后旧请求返回 403 | 读取旧请求结果 | 丢弃旧响应，不影响新项目授权 |
| KA-04 | 本地页面持续收到集群授权拒绝 | 观察当前工作负载页面和侧栏 | 内容及菜单稳定，错误局限于对应集群范围，不形成请求循环 |
| KA-05 | 系统超级管理员，没有项目角色或集群授权绑定 | 查看命名空间、工作负载并在隔离夹具新建资源 | 默认允许所有 EDO 操作，沿用当前集群凭据，不额外写入原生 RBAC |
| KA-06 | 普通成员仅获指定命名空间授权 | 访问其他命名空间或伪造管理员范围标记 | 拒绝访问，管理员缓存不得被普通成员复用 |
| KA-07 | 管理员已有缓存与操作长连接 | 撤销管理员、停用用户或修改认证版本 | 旧缓存及长连接失效；其他成员连接不受影响 |
| KA-08 | 当前项目不同，或集群 RBAC 同步失败 | 管理员访问准确集群 | 当前项目隔离继续生效；同步失败不阻断管理员恢复入口，普通成员继续拒绝 |

集群资源级授权与当前 EDO 项目授权分别处理；集群拒绝仍由服务端执行并向用户展示，不能为解决闪烁隐藏错误或授予权限。
