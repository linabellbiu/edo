# EDO 终端与文件工作区

## 使用方式

主机列表中，已启用且可用的 SSH 或本地执行能力图标可打开主机终端。主机终端停靠在页面底部，最小化后保留为程序栏，同一主机的多个会话按主机 UUID 分组。普通页面跳转、切换会话和最小化不会重新连接；关闭会话才释放连接。最多保留 8 个主机会话，每个终端最多保留 1000 行回滚输出，不将终端输出或输入保存到浏览器存储。

Docker 容器与 Kubernetes Pod 仍在当前终端抽屉中打开，不提供最小化。三类终端均可在左侧浏览当前目标内的目录、预览文本、下载、上传和编辑普通文件。它不是宿主机全盘资源的跨目标映射：容器文件就是容器命名空间内的文件，本地主机表示当前 EDO 进程所在环境；在 Compose 容器中不会穿透到物理宿主机。

文件树按需读取单层，最多显示 1000 项。UTF-8 文本预览与编辑限 1 MiB，单文件上传、下载限 64 MiB。传输流式处理，上传先写入 EDO 的独立临时文件，完整收取并核定大小后再传往目标，不将 64 MiB 文件缓冲到 EDO 堆中。文件编辑显示未保存状态，离开或关闭前确认丢弃草稿。没有删除、递归扫描或目录批量上传功能。

## RBAC

| 权限 | 能力 |
| --- | --- |
| `host.terminal.open` | 打开主机交互终端，与容器终端独立 |
| `terminal.open` | 打开 Docker 容器或 Pod 终端，不自动获得主机终端 |
| `terminal.file.read` | 列目录、预览及下载普通文件 |
| `terminal.file.upload` | 上传新文件 |
| `terminal.file.edit` | 编辑已有文件；同时需要文件读取权限 |

覆盖上传同时需要上传、读取及编辑权限，并明确确认；保存时提交原内容 SHA256，目标文件变化时拒绝覆盖。权限均为项目级，新权限不向已有普通角色自动展开；管理员在角色权限页面按需授权。文件操作还要求当前目标的资源读取权限，Pod 的文件传输由于使用 Exec，还需该命名空间的 `pods.execute` 集群授权。

主机连接复用已加密的 SSH 凭据和固定指纹，不自动 sudo，不新增任意宿主机命令 HTTP API，不将交互终端开放为对话助手工具。本地 PTY 只继承必要环境，不继承 EDO 密钥与服务连接变量。主机、项目、成员、身份和权限变化将终止过期连接；终端断线不会自动重连或重放输入。文件读取和传输期间同样持续复核权限及目标身份。

## 文件实现与边界

主机文件使用已有 SSH 连接设施配合 [pkg/sftp](https://github.com/pkg/sftp)（BSD-2-Clause），本地交互终端使用 [creack/pty](https://github.com/creack/pty)（MIT）。二者均为专门的轻量协议库，不引入远程 Agent 或额外常驻组件，不自行实现 PTY/SFTP 协议。已有 xterm、Moby 与 client-go 继续复用。依赖固定版本在 `go.mod`；替换面限制在主机 provider，不改变业务权限与审计协议。维护风险主要是平台 PTY 差异与服务器 SFTP 扩展支持，需继续维持 Linux/macOS 与隔离 SSH/SFTP 回归。

SFTP 目录读取有单包与累计响应预算。服务器缺少原子新建或原子替换所需扩展时明确拒绝，不退化为先删除旧文件。Docker 与 Pod 使用官方 Moby/client-go API，固定非交互文件协议的路径作为独立参数，不向用户交互 Shell 灌命令，也不安装工具或二进制。目标需具备 Linux `sh/stat/dd` 等基础工具；写入还需 `timeout`、`/proc` 文件描述符视图和安全的同文件系统暂存目录。兼容 GNU 与 Alpine BusyBox；缺少必要能力时明确报告不可用，不伪造空目录。

容器与 Pod 的写入采用“暂存 → 复核原文件 → EDO 再次鉴权 → 显式提交帧 → 原子发布”。传完数据或关闭连接不代表允许覆盖，提交帧发出前取消、撤权或失联不会发布暂存文件；远端等待也有 120 秒超时。提交帧发出后已进入原子发布阶段，若此时断网，结果可能未知，须重新读取核对，不自动重试或声称回滚成功。主机文件同样在原子提交前再次校验当前授权。

文件保存使用独立临时文件或私有目录、传输前后摘要校验、保留权限与原子发布，拒绝符号链接、设备和 FIFO。EDO 自身的同路径修改有界串行化；这些检查不是对同 UID 恶意进程的内核级 CAS 或文件系统沙箱。主机用户/容器原有操作系统权限及挂载边界仍生效。彻底断网或目标身份变化时可能留下本次随机临时文件，会记录安全日志，不向新身份补发清理，也不扫描或删除其他文件。

审计记录操作者、项目、目标、文件路径及结果，不记录文件内容、终端输入输出或凭据。上传、下载、编辑分别记录动作，拒绝也进入审计。文件请求、会话、目录输出和传输均有超时、并发与大小上限。

## 本地验收

`/tests/fixtures/terminal-workspace.html` 挂载真实生产组件，用内存文件和模拟 WebSocket 验证停靠、最小化、多主机、权限、文件编辑和覆盖确认，不请求真实服务器。它不是线上或真实远端资源验收证据。

后端测试使用临时目录、回环 SSH/SFTP、真实本地 PTY、隔离 Docker 测试容器和 Mock Kubernetes API；业务鉴权使用独立 SQLite/Casbin，覆盖角色、个人拒绝、项目成员及审计。测试不连接用户服务器，不操作其 CI 或部署流程。
