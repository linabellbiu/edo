# 工作负载详情界面

本次调整以指定的 Kuboard Deployment 详情页为只读参考，修正旧版大卡片和嵌套标签页造成的信息层级差异。保留 EDO 抽屉、现有权限及操作确认，不复制生产资源数据或引入新的运行组件。

## 行为变化

- 上方并排显示紧凑元数据与四列事件表，长标签、注解和事件可查看完整内容；策略默认折叠，不再占用独立大卡片。
- 下方以历史版本、对应 Pod、事件与运行状态三栏联动。版本依然按控制器 UID 关联 Pod，日志和终端按明确容器选择；旧 Pod 或跨集群的迟到回调不替换操作目标。
- 右栏原地显示 Pod 事件、CPU/内存趋势、健康条件和容器状态。普通、Init、临时容器均保留，已退出容器可查看日志；终端沿用现有策略，仅允许运行中且有权限的普通或临时容器。
- 模板改为左侧容器分类、右侧配置。关联资源返回后恢复模板分区和容器选择；选择失效时明确提示，不悄悄选中其他容器。
- 未变更数据库结构、已有资源或权限码，不需要数据迁移。

## 指标边界

现有 Pod 指标接口不提供历史序列。折线只累计本页实际收到的新鲜采样，最多 60 个；不补历史、不插值、不补零。缺失、过期、权限不足和请求失败分别提示，恢复后的真实点与故障前断线，不增加虚假失败采样；历史采样不能冒充当前用量。等待中或已退出容器的旧实例指标不显示为当前实例用量。

当前用量、请求与限制可在每张趋势图下展开核对；CPU 使用 m，容量使用 MiB / GiB。该能力不新增数据库表或后台采集任务。

## 验证方法

```sh
node --test web/tests/*.test.mjs
npm run build --prefix web
```

无真实登录态时可用开发服务器显式打开 `/tests/fixtures/workload-reference.html`，对照桌面、窄屏、深色、版本与容器切换。加 `?theme=dark` 查看深色。夹具使用实际 Vue 组件和单独标注的测试数据，拦截全部接口，不接入集群；它不进入应用路由或生产构建入口，也不能替代真实隔离集群的登录、日志、关联返回及权限验收。

生产参考站只读比较，不填写、保存或执行资源操作。发布前仍需在 EDO 真实隔离集群检查列表范围、筛选排序、详情、关联返回、编辑与日志入口，不能仅凭脚本桩或夹具截图宣布已发布。
