# EDO 流水线阶段耗时

流水线运行记录列表展示“总耗时 / 当前阶段”，运行中使用黄色圆圈呼吸，失败红色、成功绿色。详情执行拓扑继续按本次运行的不可变快照显示各阶段耗时；同次发布的多个应用在各自运行详情中分别显示，不合并不同应用的时间。

总耗时复用已有任务时间查询，取最早实际进入时间到最终结束时间的跨度，包含有记录的代码源与阶段间等待。并行任务不相加，结束后固定；缺少时间依据时显示“耗时未知”，不使用运行更新时间填补。具体回归见 `docs/acceptance/run-progress-20261105.md`。

- 阶段开始：首个非跳过任务实际进入该阶段的时间，复用任务创建时间；包含排队、审核、放行、重试及阶段内任务之间的等待。
- 阶段结束：最后一个已执行任务的结束时间。并行任务使用时间跨度，不相加；阶段间不互相借用时间。
- 正在执行或等待的阶段：服务端返回当前已用时间，页面使用单调时钟递增；服务端状态刷新后重新校准，完成后停止计时。
- 失败或停止：保留已执行部分的实际跨度。后续没有进入的阶段显示“未执行”；运行尚未到达的阶段显示“未开始”。全部跳过的阶段显示“已跳过”。
- 缺少历史记录、结束时间缺失或时间无效：显示“耗时未知”，不以流水线更新时间、其他运行的数据或零值填补。

复用现有 GORM 查询及 Vue 定时刷新，不引入第三方组件或数据库迁移。每次运行列表读取只增加一次当前项目范围内的批量任务时间查询，不逐行请求；列表与详情继续只要求 `pipeline_run.read`，不扩大执行权限，也不返回脚本、凭据和原始任务日志。
