# 部署表单与上游产物引用验收

上游文件通过 `${BUILD_ARTIFACT}` 等变量引用前序构建声明的同名暂存构建物。保存和创建运行时必须唯一匹配，运行后继续按项目、流水线、任务和制品身份校验下载；不查询尚未生成的产物作为表单选项。旧的明确任务或构建方案关联保持可执行。

Docker、单服务 Compose 和多服务 Compose 均始终显示镜像仓库。唯一上游镜像仓库自动回显，用户指定值优先；没有构建阶段时可指定仓库、镜像和实际 Tag。Compose YAML 中匹配的所选镜像在部署时替换为运行快照冻结的 Digest，其余镜像和容器环境占位符保持原样。

| ID | 角色、前提 | 步骤 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| DEP-FORM-01 | 流水线编辑者，前序构建声明 BUILD_ARTIFACT | 输入裸变量，再改为 `${BUILD_ARTIFACT}`，保存启用并生成运行快照 | 裸变量提示格式错误；正确引用解析并冻结准确任务和命名产物 | 本地页面、正常保存启用及运行快照回归通过 |
| DEP-FORM-02 | 同名、缺失、同阶段或后序产物 | 分别尝试引用 | 拒绝缺失和歧义，不静默选择、不读取后序任务 | Go 竞争检测通过 |
| DEP-FORM-03 | 上游配置产物包含 Compose 文件 | 输入 `${CONFIG}`，运行后读取归档中的 YAML | 解析服务并固定实际正文，不依赖配置表单时存在产物 | 隔离制品归档及快照回归通过 |
| DEP-FORM-04 | 编辑者，已有唯一上游镜像仓库 | 打开 Compose 部署，再指定其他来源 | 仓库始终显示，默认上游值，显式选择不被覆盖；撤权后不能修改 | 本地页面及前端回归通过 |

| DEP-FORM-06 | 编辑者，有 Compose 草稿 | 键盘收起、展开、全屏及关闭全屏 | 状态、焦点语义正确，草稿保留；其他 YAML 编辑器默认不折叠 | 本地浏览器通过 |

| DEP-FORM-08 | 可编辑部署方案 | 展开底部高级选项，修改健康检查地址、共享变量及超时，再收起 | 默认折叠；字段标签不带“可选”，值与原方案使用同一保存路径；撤权及跨项目回调不能修改 | 本地页面及前端回归通过 |
| DEP-FORM-09 | 已关联库方案，有修改权限 | 点击“原部署配置”标签旁“修改”链接 | 进入准确方案并保留执行配置交接；不再显示下面的修改原配置按钮 | 本地页面及前端回归通过 |
| DEP-FORM-10 | Compose 编辑器及只读预览 | 检查标题、上传、收起/展开与全屏位置；改变折叠状态 | 共享对齐操作栏，草稿保留；仓库选择在部署方式之后 | 本地页面及前端回归通过 |
