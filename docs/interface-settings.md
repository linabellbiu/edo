# EDO 界面设置

“系统设置 → 界面设置”提供“显示 GitHub 标识”，控制所有用户页面顶部的标识与仓库链接，默认开启。拥有 `config.read` 可查看设置，`config.update` 可保存；普通登录用户只读取这个非敏感显示状态。配置保存到现有系统配置表，保留版本冲突检查、修订和操作审计，没有新增数据库列或第三方依赖。

保存后当前页面立即更新，其他页面刷新、重新进入或回到窗口时读取最新状态。状态加载前不显示入口，避免已关闭的标识短暂闪现；读取失败不覆盖已确认的状态，并在设置页明确提示。关闭显示不会修改 Git 凭据、仓库连接或流水线。

| ID | 角色、前置与操作 | 预期 |
| --- | --- | --- |
| UI-LOGO-01 | 管理员首次打开界面设置，关闭并保存，再刷新 | 默认开启；关闭持久化，顶部标识与链接消失 |
| UI-LOGO-02 | 普通登录用户与未登录请求读取、尝试修改 | 普通用户可读统一状态但不能修改；未登录请求被拒绝 |
| UI-LOGO-03 | 管理员重新开启；另一编辑者用旧版本保存 | 正常重新显示；旧版本冲突，不覆盖新设置 |
| UI-LOGO-04 | 切换身份、请求失败、保存时旧读取迟到 | 过期结果不恢复图标或草稿；错误不伪报成功 |

本地验证：正常 HTTP 覆盖默认状态、管理员保存、普通用户读取与拒绝修改、未登录拒绝和旧版本冲突；配置服务重建后仍读取已保存状态及修订。前端覆盖保存联动、并发读取合并、迟到响应、失败和撤权。本地合成页面实际完成关闭保存、刷新保持关闭、重新开启后恢复顶部链接；合成页面仅保存浏览器内测试数据，没有修改线上配置。
