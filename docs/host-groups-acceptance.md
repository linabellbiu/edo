# 主机组与部署目标验收

使用独立本地 EDO、SQLite、Redis 及专用 PostgreSQL / MySQL 实例，不操作生产主机。

| ID | 角色与前置 | 操作 | 预期 | 当前结果 |
| --- | --- | --- | --- | --- |
| HG-01 | 管理员，已有部署方案 | 打开流水线任务，修改任务名称后保存回读 | 不显示只读部署方式；新任务默认名称为部署方式，旧自定义名称保留 | 真实页面修改名称、保存及重新打开通过；前端回归通过 |
| HG-02 | 管理员，原主机及分组 | 从主机页创建顶层及下级分组，改名、移动并回读 | 名称与层级持久化，原 UUID、主机和部署关联保留 | 服务及 HTTP 通过；真实页面完成创建下级、改名、移动到顶层及回读 |
| HG-03 | 管理员，两个项目 | 重名创建或改名，选择自身、下级或其他项目父组，删除有下级的组 | 稳定中文提示，拒绝非法改动，不泄露其他项目详情 | 服务及 HTTP 通过 |
| HG-04 | 管理员，旧库及独立新库 | SQLite、PostgreSQL、MySQL 建库、升级、重复迁移、继续写入；旧重名数据升级 | UUID/成员不变，名称全局唯一；重名时阻断并保留数据，修正后可重试 | 三种数据库真实测试通过 |
| HG-05 | 有部署权限，组内多主机 | 选择组、默认全选，取消部分主机后保存并运行 | 只执行勾选主机，每台结果可追踪；多组成员关系保留 | 真实页面默认全选、取消一台、保存和重开通过；方案库及自定义方案的全部成功/单台失败、逐主机记录和快照隔离通过。执行端使用可控替身，未对真实远端主机发布 |

最终验证：1773 条前端测试与生产构建通过；最后的主机选择及编辑回归 50 条通过。数据库、主机、分组服务、相关 HTTP、流水线目标和应用分组回归通过，Go 测试启用 race。主机包首次在沙箱内因本机监听被拒绝而失败，允许隔离监听后重跑通过。MySQL 首次缺时区表，专用实例载入系统时区后真实迁移通过。


执行范围规则：选择主机组后默认勾选本组全部可用主机，可逐台取消；保存后固定勾选集合，后来新增成员不会自动进入已保存方案或历史运行。单台主机可加入多个组；主机列表选择父组时汇总子组并去重，部署勾选明确标为“本组可用主机”。

多主机沿用已有并行任务执行机制，每台主机生成稳定任务身份及独立日志和发布记录，整组不会因首台成功而提前成功。已移除或失效的勾选主机阻断运行，空勾选不回退为自动选择。勾选持久化字段在 SQLite、PostgreSQL、MySQL 分别验证全新建库、升级、重复迁移和继续写入；旧单主机记录保持原样。

正常接口验证多主机保存、空选择拒绝以及非首台勾选主机的成员关系保护。完整部署包与流水线包通过 race 回归；追加的方案库/自定义方案全部成功、单台失败、组外/重复/空主机拒绝和精确回滚测试通过。真实页面深色桌面及 390 px 窄屏已核对；修复树组件隐藏测量节点造成的横向溢出，页面实际宽度恢复为 390 px。
