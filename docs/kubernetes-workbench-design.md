# Kubernetes 工作区骨架与设计语言

本文件定义 EDO Kubernetes 工作区（集群总览、节点、工作负载、配置中心、存储、服务与网络）的统一页面骨架、令牌和交互约定。后续页面调整以本文件为准；登录页、主侧栏和其他业务线不在此范围。

## 1. 页面骨架

所有 K8s 页面共用同一顺序，不再各自拼装页头：

1. **上下文卡**：左侧「集群列表」返回、集群名称与 API 地址；右侧关联主机或「独立集群」标识。整块是一张 12px 圆角白卡，不承载业务操作。
2. **工作区网格**：左侧范围树（集群 / 命名空间，或集群级页面的集群列表），右侧资源面板。列宽 210px + 自适应，间距 12px；宽度 ≤1000px 时堆叠为单列。
3. **资源面板**：一张 12px 圆角白卡，自上而下为
   - **面板头**：资源类型页签（带计数）、节点视图切换（列表 / 拓扑）、右侧「自动刷新」「刷新」「新建」；
   - **工具栏**：搜索、状态筛选、标签筛选、清除筛选，单行排列，控件 32px 高、8px 圆角；
   - **元信息**：节点和工作负载使用 12px 次要色显示资源类型、筛选后 / 总数和最近同步时间。服务与网络、配置中心及存储将筛选后 / 已加载数量合并到工具栏，仅在筛选或部分加载时显示，最近同步时间在刷新按钮上查看；
   - **表格**：表头 40px 冷灰，行高 56px，末行保留横向底边；
   - **分页**：右对齐，与表格以分隔线断开。
4. **卡片与页面**：页面底色沿用全站 `--edo-bg`（#f5f6f8），卡片纯白、1px `--kube-border`、无阴影堆叠。所有卡片圆角 12px，控件 8px。

## 2. 令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--kube-radius-card` | 12px | 面板、上下文卡、范围树、总览卡片 |
| `--kube-radius-control` | 8px | 按钮、输入框、下拉、工具控件 |
| `--kube-heading` | #eef2f6 / #253242 | 表头、卡片分区标题 |
| `--kube-border` | #d9e1eb / #3a495c | 卡片与分隔线 |
| `--kube-link` | #315fae / #b7cef5 | 资源名、链接、修改类操作 |
| `--kube-warning` | #855414 / #e5c998 | 运行类风险操作、异常状态 |
| `--kube-danger` | #a23448 / #edb1bf | 删除与失败 |

正文 13px，辅助信息 11–12px，表头 12px/600；数字统一 `tabular-nums`。容量使用 GiB / MiB（1024 进制），CPU 用核或 m。

## 3. 表格语言

- 表头固定高度 40px、冷灰底、12px 600、次要色文字；排序按钮保留 `aria-sort`。
- 行高 56px，左对齐；名称列允许两行（名称 + 标签/镜像摘要），其余列单行省略并提供 `title`。
- 服务与网络、配置中心及存储共用紧凑表格。搜索与标签按内容限定宽度，命名空间、状态和端口标签至少 24px 高。「编辑」用共用中蓝实底白字，「YAML」与「访问提示」用浅蓝底深蓝字，「更多」用主题中性色。资源名进入详情，已经单独列出的标签不在名称下重复展示。
- Service 详情在端口映射表逐行提供「访问提示」，按实际配置显示 Pod DNS、集群 IP、NodePort 和已分配或已配置的外部地址。无头服务与 ExternalName 按 DNS 行为提示。按钮支持点击和键盘，提示中的地址可选中复制。
- 悬停使用 `color-mix(in srgb, var(--edo-primary) 5%, white)`；不使用斑马纹，避免和选中态混淆。
- 操作列固定在右侧：主操作「详情 / 编辑」用描边按钮（8px 圆角、28px 高），其余收进 ⋯ 菜单。
- 横向溢出时，固定操作列才显示阴影；完整显示或滚到最右后必须消失。

### 资源用量条

节点与工作负载里的 CPU / 内存 / Pod 用量统一为「指标名 + 细轨道 + 百分比 + 实际值」：
- 填充统一使用品牌色 `--kube-meter-fill`，轨道 `--kube-meter-track`；不再为三种指标分配深绿、深蓝、深青三套底色。
- 达到 75% 转 `--kube-meter-warning`，达到 90% 转 `--kube-meter-danger`，百分比文字同步变色；未知或无权限只显示空轨道，不画成 0%。
- 轨道高 6px、圆角 3px，行高 24px；百分比 `tabular-nums` 右对齐。
- 容量写作「已用 / 总量」，不再用方括号包裹：已用值用正文色、总量用次要色，斜杠按列对齐，避免每行宽度参差；完整数值与单位同时提供给屏幕阅读器（`aria-valuetext`）。

## 4. 动作层级与配色

| 类别 | 颜色 | 例 |
| --- | --- | --- |
| 查看 / 修改 | 品牌蓝（描边；详情抽屉内为实底） | 详情、编辑、YAML |
| 运行 / 风险 | 琥珀（描边；抽屉内为实底） | 滚动重启、调整副本 |
| 删除 | 红色 | 删除、移除节点 |
| 中性 | 冷灰 | 刷新、更多、取消 |

破坏性操作必须走确认弹窗并保留影响说明；只读资源不显示可点击的假按钮。

## 5. 状态与三态

- 状态只由真实字段决定：成功绿、进行中蓝、警告琥珀、失败红、未知 / 缩容中性灰；颜色不能单独表意，必须同时有文字。
- 加载：保留表头与已有行，工具栏按钮显示 loading；首次加载用骨架或居中提示，不整页闪烁。
- 空态：区分「没有数据」「筛选无结果」「无权限」「未选择命名空间」，并给出下一步（清除筛选 / 选择命名空间 / 新建）。
- 错误：就地显示在所属模块，带「重试」，不使用全局遮罩。

## 6. 不改变的部分

页面骨架与样式调整不改变路由、权限码、确认流程、真实请求、UID / resourceVersion 校验和只读约束；也不把参考站（Kuboard）的写操作引入 EDO。

## 7. 验收

```sh
node --test web/tests/kubernetes-*.test.mjs
npm run build --prefix web
```

浏览器预览：开发服务器打开 `/tests/fixtures/kubernetes-workspace.html`，支持 `?view=overview|nodes|workloads|config|storage|network`，叠加 `&theme=dark`。检查点：上下文卡与面板同宽对齐、工具栏单行、表头/行高一致、操作列不换行、深浅主题对比度、≤1000px 堆叠与键盘焦点。
