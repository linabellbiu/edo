# 全局提示、抽屉与集群入口整理

本次使用 ui-ux-pro-max 检查 EDO 全局，范围包括普通说明、状态与风险提示的配色，抽屉布局，以及集群相关操作的归属。保留现有品牌、导航、主题和业务权限。

## 检查范围与决定

- 扫描 125 个 Vue 页面和组件：226 处 Alert，其中普通信息 55 处、警告 97 处、错误 57 处、成功 8 处、动态状态 9 处。分别核对用途，普通信息统一使用主题中性色，真实风险、失败、成功及交互选中保留语义色。
- 主机与接入中的独立运行时、K3s/k3d 正常模式说明、脚本配置前提、无历史制品时按 Commit 重建属于普通信息。助手未启用且没有 Key 属于配置状态；已启用但缺 Key 才使用警告。
- 服务商、DNS 类型、制品类型、变量范围、部门类型及角色数量使用中性标签。当前版本、运行状态、错误和敏感权限保留对应强调。
- 扫描 41 处抽屉，共用部署阶段的紧凑标题、16px 内容间距、13px 表单标签和固定底部操作区。8 处原先在正文或顶部的提交入口移至底部；外置提交按钮仍关联原生表单，继续触发原校验。日志、终端及详情内容保留必要布局。
- 主机、Docker、凭据、接入集群、登录方式、配置文件及部署配置按实际字段补齐基础信息、连接、凭据、范围或内容分区。端口及数量输入最大 160px，并受可用空间约束。
- 创建集群只在集群列表提供一次；集群名称进入对应总览，无资源查看权限或已停用时查看详情。详情用于连接与主机关联信息；授权在该集群的更多操作中。接入入口继续位于总览，资源工作区不重复创建和授权。主机组新建保留在分组树，删除页头重复入口。全站保留标签栏中的页面刷新入口。
- 修复共用详情抽屉的空标题属性遮住自定义标题的问题，集群详情恢复显示准确名称和状态。

## 固定验收用例

| ID | 前置与操作 | 预期 |
| --- | --- | --- |
| UI-01 | 浅色、深色查看普通说明及真实警告/错误 | 普通信息中性；警告和失败清晰可辨；链接和键盘焦点仍可用 |
| UI-02 | 在主机、凭据、配置及登录方式抽屉滚动至底部 | 标题、分区、间距一致；操作固定在底部；窄屏不溢出 |
| UI-03 | 在隔离配置表单从底部提交无效输入，再提交有效输入 | 原验证仍执行；无效输入不保存，成功路径沿用原函数；不连接真实部署目标 |
| UI-04 | 集群列表为空或有数据，管理员和只读用户分别查看 | 创建入口最多一个，按权限显示；集群名称进入准确目标，停用或无资源权限时仅查看详情 |
| UI-05 | 从列表进入总览，再进入工作负载并返回 | 集群及命名空间准确；总览和资源页没有重复创建/授权入口；浏览历史可返回 |
| UI-06 | 在隔离授权界面打开启用/关闭弹窗，取消或 Esc 返回 | 普通说明中性，确认弹窗居中，取消不写入，焦点返回触发按钮 |

验收以实际页面和对应业务回归分别记录；源码扫描不冒充每个表单的真实外部执行。真实集群与部署配置只读查看，不为视觉验收提交变更。

## 本地验收记录

- UI-01：配置抽屉浅色桌面及深色 390px 已查看，普通提示实际背景使用主题中性色；错误校验继续显示红色。
- UI-02：实际主机表单、配置表单、集群详情和授权抽屉已检查。配置抽屉深色 390px 分区及固定底部无溢出，取消与保存均可见。其余抽屉通过共用样式、模板编译与业务回归覆盖，未逐一提交真实配置。
- UI-03：隔离配置表单通过底部按钮提交，空文件名被原校验拦截，填写有效文件名及 YAML 后成功保存并回到列表。仅写入内存合成数据。
- UI-04：真实列表组件已验证有数据、空列表、无创建权限、无资源权限和停用分支；创建入口最多一个，名称导航使用准确集群 UUID。
- UI-05：隔离页面已从集群名称进入总览，再进入 Deployment 并返回，保留集群和命名空间；资源页没有重复创建或授权按钮。
- UI-06：已从集群列表更多菜单打开授权，在深色 390px 检查关闭映射居中弹窗，Esc 取消后焦点回到关闭映射按钮；真实集群未执行映射启停。
- 使用与 CI 相同的 Node 24 命令运行全部前端回归，1892 项通过；TypeScript 校验及生产构建通过。更新两处落后于既有 Service 表单及端口标签行为的断言，保留全部可访问名称与绑定、协议验证。
