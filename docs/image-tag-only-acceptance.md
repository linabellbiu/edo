# 镜像 Tag 语义修正验收

`${EDO_IMAGE_TAG}` 只表示版本 Tag。镜像名称与仓库由用户在部署配置中填写，部署不再要求关联构建任务；本次不修改业务仓库或触发业务流水线。

| ID | 角色与前置 | 操作 | 预期 |
| --- | --- | --- | --- |
| TAG-01 | 有流水线编辑权限、默认或自定义镜像名 | 分别从 Git Tag 与分支创建镜像构建运行 | 内置变量为 Tag 或 12 位短 Commit SHA，不含名称与仓库，构建无 Tag 输入 |
| TAG-02 | 内联或库部署方案，多个上游镜像 | 打开并保存部署任务 | 无镜像构建关联入口，不要求显式选择来源任务；多个同 Tag 产物可直接提供 Tag |
| TAG-03 | 仅部署流水线或用户自定义部署镜像 | 使用 `registry.example.com/team/app:${EDO_IMAGE_TAG}` | 新运行按用户填写的名称、仓库及版本解析镜像，不建立服务与构建任务映射 |
| TAG-04 | 曾保存完整镜像关联的任务或已完成运行 | 创建新运行、读取原配置、恢复历史重建上下文 | 新运行使用纯 Tag 并忽略旧关联；不回写或删除已保存关联与不可变历史运行 |

继续复用现有 compose-go、Distribution reference 及流水线制品查询，无新增依赖或组件。执行结果见本次交付与本地发布回执。

部署镜像的最新执行与日志规则见[Compose 镜像与执行日志验收](compose-execution-transparency-acceptance.md)：新运行保留用户 Tag，不自动替换为摘要。
