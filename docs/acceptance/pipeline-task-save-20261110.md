# 流水线任务保存与镜像常规配置验收

任务属性面板底部固定显示保存操作，常规和高级配置共用；沿用整条流水线的保存、版本校验、失败草稿保留及已启用更新确认。镜像名称与 Tag 在常规配置中、构建参数之前显示。新建镜像任务或首次编辑未配置 Tag 的镜像任务时，实际填入 `${EDO_GIT_TAG}`，已有值和本次明确清空的输入继续保留。只读查看不补写默认值。

| ID | 角色与前置 | 操作与预期 | 结果 |
| --- | --- | --- | --- |
| PTS-01 | 可修改；草稿镜像任务 | 打开任务，常规配置看到镜像名称和实际默认 Tag；面板保存后重新打开，名称与 Tag 均保留 | 通过：真实 Vue 页面、合成保存适配器；组件及状态回归 |
| PTS-02 | 可修改；库方案与自定义构建 | 新建镜像任务、首次选择镜像方案、从脚本切换镜像构建，默认值均为 `${EDO_GIT_TAG}`；脚本构建不补镜像 Tag | 通过：状态及保存载荷回归 |
| PTS-03 | 可修改；已有镜像配置 | 修改名称、Tag，切换构建来源并重开；自定义值及明确清空的当前草稿不被覆盖 | 通过：状态、保存往返回归 |
| PTS-04 | 可修改；已启用流水线 | 点击保存并更新，先确认再提交；后续沿用已有启用语义 | 通过：原确认流程及正常提交回归 |
| PTS-05 | 只读；已有镜像方案 | 打开面板，不显示保存操作，不改写缺省 Tag；直接调用保存仍不能发出写请求 | 通过：渲染及权限状态回归 |
| PTS-06 | 可修改；长表单与 390×844 窄屏 | 常规与高级分区、滚动内容后，固定保存栏仍在视口内、可点击，不产生页面横向溢出 | 通过：本机合成页面真实浏览器检查 |
