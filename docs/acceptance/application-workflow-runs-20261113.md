# 应用流水线阶段执行概览

应用详情中的关联流水线默认直接显示当前运行，无须展开；历史执行提供独立展开按钮，展开后显示该应用与该流水线最近 50 条已结束运行。查看与展开只读取数据，不触发执行；阶段名称、状态与耗时来自运行快照，不用当前草稿或任务名称替代阶段。

| 用例 | 角色与前置 | 操作 | 预期 |
| --- | --- | --- | --- |
| AWR-01 | 可查看应用、运行；同应用有两条流水线 | 分别展开与收起 | 各自按应用与流水线读取，不串用记录；名称仍为唯一编辑器入口 |
| AWR-02 | 有一个较旧的运行中记录与 65 条历史记录 | 展开 | 当前运行置前，历史按自增顺序倒序取 50 条，不被全局列表或历史分页挤掉 |
| AWR-03 | 阶段中有多个并行任务 | 查看每条执行 | 横向只显示阶段，不显示任务拓扑和任务表；失败、等待、跳过、未知分别展示 |
| AWR-04 | 运行中、已完成、失败与缺失采样 | 查看耗时与阶段状态 | 只运行中的真实采样持续计时，终态停止；缺失数据不显示为 0 或成功 |
| AWR-05 | 正在读取，切换项目、流水线、撤权或关闭 | 等待旧响应返回 | 取消旧请求、清理旧数据，迟到响应不得串入新范围；无权限不读取运行 |
| AWR-06 | 有已有记录，接口暂时失败 | 刷新并重试 | 明确错误并保留已有记录，不能伪装无历史；恢复后清除错误 |
| AWR-07 | 已展开，发生运行事件或页面隐藏 | 查看更新 | 复用共享状态订阅合并刷新；隐藏停止读取，可见立即恢复；断线低频校准 |
| AWR-08 | 正常本机页面、浅色、深色与窄屏 | 键盘展开、收起，查看当前及历史，打开日志 | 布局紧凑、阶段可读、焦点可见；日志沿用实际运行 UUID 与权限，不自动执行 |
| AWR-09 | 固定提交与作者、Committer、触发者不同；重复 Commit 或缓存缺失 | 查看当前及历史的提交人 | 使用固定 Git 对象的 Author.Name，按冻结仓库和 Commit 去重读取；只读本地缓存，不下载 Git、创建缓存或返回作者邮箱；无法取得时明确显示未记录 |

复用现有 GORM 查询与项目隔离、Ant Design 表格展开行、共享 WebSocket 订阅和阶段计时组件；不增加第三方依赖。查询必须在分页前限定应用、流水线及当前/历史状态，不能先截取全局运行再由浏览器拼出历史。
