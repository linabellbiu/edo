# K3s 卸载后移除 EDO 记录

本批只调整官方卸载成功后的 EDO 元数据处理，不改变官方脚本，不连接主机补执行卸载。复用已有独立卸载权限、精确手动口令及正常卸载页面入口。安装与卸载历史保留。

| ID | 角色与前置 | 操作 | 预期 | 验证 |
| --- | --- | --- | --- | --- |
| UC-01 | 有卸载权限；单节点连接 | 执行并验证官方卸载 | 移除连接、准确主机关联及本地授权映射；历史、Host、SSH/Docker 和其他连接保留 | 后端独立数据库回归通过 |
| UC-02 | 有卸载权限；多个关联主机 | 卸载其中一个 | 只解除本主机关联，保留其他主机和集群连接 | 后端独立数据库回归通过 |
| UC-03 | 有卸载权限 | 模拟官方脚本失败、验证失败和元数据事务失败 | 保留连接；元数据失败回滚并提示官方卸载已完成、无需再次卸载；不重放脚本 | 后端独立数据库回归通过 |
| UC-04 | 已成功的旧卸载任务 | 仅补处理 EDO 记录并重复调用 | 幂等移除，无 SSH 读取或执行，原失败安装历史不变 | 后端独立数据库回归通过；本地旧任务补处理通过：连接和关联均归零，原两条安装/卸载历史及主机保留，新增一条事务审计 |
| UC-05 | 目标变更、跨项目或撤权 | 补处理旧任务或确认后变更连接 | 拒绝移除已变更或越权目标，保留关联 | 后端独立数据库回归通过 |
| UC-06 | 正常卸载页面 | 查看确认提示和结果、精确口令及完成事件 | 提示成功后移除的影响；原 RBAC、二次确认、结果精简及完成刷新保留 | 前端 33 项回归、构建通过；浏览器已核验新移除提示，精确口令及完成事件复用前端回归 |

本轮不重新运行真实主机卸载；已有官方成功任务的元数据补处理与完整新安装/卸载验收分别记录。

验证命令：`go test -race ./internal/k3s ./internal/httpapi -run 'Test(Uninstall|K3sUninstall)' -count=1 -timeout 180s`；最终新增任务互斥与审计断言另行定向回归通过。`node --test web/tests/k3s-uninstall.test.mjs web/tests/k3s-progress.test.mjs` 共 33 项通过，`npm run build` 通过。
