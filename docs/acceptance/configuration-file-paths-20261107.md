# EDO 配置文件路径调整与验收

日期：2026-11-07。

用户取消独立的“配置生成根目录”，将“生成路径”改为“配置文件路径”。新部署直接使用所填路径，不再添加 `~/edo/deply` 或项目、应用、环境、运行及任务目录。

- `/srv/app/.prod.env`：写入该绝对路径。
- `~/settings/app.toml`：在目标执行用户的主目录下写入。
- `config/application.yaml`：相对于部署工作目录；没有工作目录的部署使用目标执行用户主目录。

ENV 自动注入及显式 `--env-file` 复用同一文件路径，主目录在执行目标解析。首次部署入口传入目标工作目录，重启、重建沿用成功发布快照中的路径和参数，并按原规则更新正文。

旧运行保留原快照的目录规则，避免升级改变已有实例的文件位置。新运行使用明确的路径模式标记；保存新流程会清除旧根目录字段。没有迁移、搬动或删除历史配置文件。

复用现有 Go 标准库路径处理与 `mvdan.cc/sh/v3` 参数解析，没有引入新依赖。继续保留配置读取及执行权限、路径穿越拒绝、符号链接检查、0600 权限、同目录临时文件原子替换和秘密正文脱敏。
