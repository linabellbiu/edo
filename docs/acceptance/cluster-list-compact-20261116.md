# 集群列表与接入入口优化

用户最新要求“集群 → 接入集群”，取消集群列表详情，把重要信息直接展示在列表。此要求取代此前在集群总览接入的入口安排。

## 最终行为

- 集群列表工具栏保留唯一“接入集群”，继续检查 `cluster.create`；安装用的“创建集群”独立保留原权限。总览不再挂载接入按钮或抽屉，主机表单只选择已有集群，不再通过加号重复接入；原 `create=kubernetes` 深链继续兼容。
- 取消列表详情按钮及详情抽屉。名称旁展示真实连接状态点，完整状态与失败原因支持悬停、键盘聚焦和点击查看；检测中、失联、受限、停用和未知继续区分，不把启用状态当作连接成功。共享状态组件默认文字模式不变，部署选择器继续展示真实连接文字。
- 列表直接展示 API 地址、默认命名空间、接入方式、关联主机及角色/地址、最近更新时间；手动连接测试取得的 Kubernetes 版本仍可显示。浅中性边框标签区分信息，长名称及地址省略并保留完整查看，多主机按第一台与 `+N` 展示，展开可读全部主机与真实角色。
- 列表直接编辑；更多菜单保留授权、主机关联、连接测试及启停权限。名称只在集群启用且有资源查看权限时进入总览；其他情况直接阅读列表，不打开详情或换目标。旧集群定位链接仍定位并标出对应行。

复用现有 Ant Design Vue Table、Tooltip、Popover 与 Drawer，不新增依赖，不改变 kubeconfig 加密、保存前连接验证、后台连接检测、主机归属或 Kubernetes 操作逻辑。

## 验证

| 场景 | 结果 |
| --- | --- |

| 无主机接入 | 真实页面在隔离合成接口中先测试再保存，两个请求均不发送 `host_ids`；成功关闭表单并刷新原列表，新行显示未关联主机，不导航到详情 |
| 编辑、主机关联及 RBAC | 准确当前对象、错误与撤权、保存刷新、主机身份、独立授权等回归通过；直接编辑仍默认保留已保存配置，不回填密文 |
| 完整信息与键盘 | 三台主机的完整名称、地址和真实角色可展开；Tab 到连接点有可见焦点并显示完整错误提示；点击 API 地址可查看全文 |
| 深浅主题与 390px 窄屏 | 五类连接状态均保持 64px 行高，列宽合计 1172px；窄屏页面宽度 390px，表格在 368px 容器内独立横向滚动，固定操作列保留。深色主机链接采用浅蓝色，正常信息使用中性边框 |
