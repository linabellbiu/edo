# EDO 主机列表密度优化

| ID | 角色与前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| HD-01 | 主机查看者，资源正常或缺失，包含长名称和多分组 | 查看主机列表 | CPU/内存、根目录/系统各占一行，缺测仍为空；名称与分组不撑高行，表格内容不丢失 | 通过 |
| HD-02 | 具有对应查看权限，主机有多个分组及流水线 | 打开分组摘要、流水线列表、主机详情和 Docker 入口 | 完整内容可访问，仍定位原主机、流水线及运行时；操作权限不变 | 通过 |
| HD-03 | 浅色、深色、窄屏 | 浏览、横向滚动和键盘聚焦 | 行列清晰，正文可读，固定操作列与横向滚动保持原行为，页面不撑宽 | 通过 |

沿用 UI/UX 技能的表格横向滚动、长内容省略及可读行距建议。仅作用主机列表：目标普通行高 64px、表头 40px，列宽合计由 1540px 缩至 1416px；资源详情保留原布局。使用现有 Ant Design Vue 表格、Popover 和共享资源格式化，不增加依赖，不修改采集、权限、安装或运行控制逻辑。

验收使用 `web/tests/fixtures/hosts-workspace.html` 的真实 Vue 页面与隔离合成接口，不连接业务 API 或实际主机。基线同一窗口测得普通行约 85.5px，长名称/多分组行约 104.1px。

验证结果：同一 1600px 视口，普通、长名称、多分组和三条流水线的行高均为 64px，正文保留 13px，表头仍清晰分隔。多分组可点击展开完整名称；长主机名称能进入原详情，详情资源布局保持原样；三条流水线的展开列表保留各自 application/workflow UUID 链接；Docker 图标仍直接打开当前主机的运行中容器。

浅色、深色和 390px 窄屏页面通过；窄屏整页宽度 390px，表格在 368px 的容器内独立横向滚动。滚动到最右侧后原生固定列阴影消失，深色链接使用现有浅蓝主题色。缺少根目录容量继续显示“—”，停用和未取得资源不显示为零。主机资源、权限及页面夹具回归 34 条通过，类型检查和生产构建通过，浏览器无脚本错误。临时目录最初误用系统 Node 25，因其全局 localStorage 形态触发夹具失败；改用项目 Node 24 后相同回归全部通过，未改产品逻辑或降低断言。

本次仅修改主机列表和资源摘要的可选紧凑展示，未更新运行实例，未执行实际主机操作。
