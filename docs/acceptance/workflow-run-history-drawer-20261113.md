# 应用流水线当前执行与历史抽屉

| 用例 | 角色与前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| WRD-01 | 有运行查看权限，当前无执行 | 打开应用关联流水线 | 行下只保留紧凑状态栏，无大块空白；历史抽屉默认关闭，不读取历史 | 通过：隔离桌面页面实测空闲区域 36px；默认只发起 active 查询 |
| WRD-02 | 同一流水线有进行中执行 | 读取、同步至完成 | 行下直接呈现当前、提交人、真实阶段和耗时；多条当前记录有界滚动；日志入口保留 | 通过：当前默认展示、提交人/阶段/耗时及日志目标验证；5 条当前有界滚动（上限 180px），同步与终态由回归验证 |
| WRD-03 | 有当前和历史执行 | 打开、关闭历史及查看日志 | 右侧抽屉最多展示最近 50 条，按准确应用/流水线查询；关闭保留当前区域与焦点 | 通过：实际右侧抽屉显示 50 条，历史查询包含准确应用/流水线；关闭保留当前，焦点回到历史入口，Tab 后进入刷新 |
| WRD-04 | 抽屉打开且旧读取尚未返回 | 切换流水线、项目或撤权 | 关闭抽屉、取消旧读取，迟到结果不串入新范围，不自动打开新历史 | 通过：单元回归覆盖打开时切换范围、撤权和迟到响应；页面验证无权限隐藏当前且禁用入口 |
| WRD-05 | 无权限、读取失败、深浅主题及窄屏 | 查看及重试 | 不越权读取，失败明确显示且可重试，名称和操作可读，当前与历史独立 | 通过：页面验证当前和历史读取失败均明确提示及重试入口；390px 深色布局无横向溢出，桌面浅色通过 |
