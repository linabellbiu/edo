# k3d 本地主机与动态能力检测

日期：2026-11-16。

本地目标复用 EDO 当前项目已有的 Docker 能力与运行时连接，原生 K3s 的 SSH 边界保持不变。不以业务主机名称、固定 IP 或预设支持平台判断能力。

| 范围 | 验证结果 |
| --- | --- |
| 主机与权限 | 当前项目可见且启用的本地主机可选；Docker 未就绪明确禁用。其他项目、停用主机、失效能力及只有查看权限的账号被拒绝，拒绝前不访问运行时 |
| 实际支持情况 | Docker 服务端返回架构、版本、CPU 和内存；runc 按官方最低要求核对。平台工具从官方 Release 清单及摘要动态读取，未知平台与缺少摘要被阻止，不写支持平台白名单 |
| 只读检测 | 检测及预览不创建集群、容器、安装任务或工具缓存；不会触发 SSH/sudo。无法读取的空闲容量保留警告，已有集群和 Docker 发布端口阻止重复创建 |
| 冻结与执行 | Docker 配置、证书及 daemon 身份进入私有快照。配置或 daemon 改变后旧任务不能创建资源；本地与 SSH 使用同一组官方 CLI 参数，默认 kubeconfig 更新关闭 |
| 创建与资源 | 官方 CLI 输出镜像分层拉取，按准确安装与集群标签及容器 ID 设置/核对 Server、Worker 限额。错误归属、资源不符不成功，失败不清理现场，不关联物理节点 |
| 日志与恢复 | 实际输出按原有有界脱敏流程持久化，启动日志按准确容器读取，阶段结束取消并等待观察器。kubeconfig、Docker 认证环境不进入日志或公开响应 |
| 性能与页面 | 一次任务复用 Docker CLI 会话，不逐节点查询 SQL；提交事务内复用同一数据库连接，单连接池回归通过。累计内存按 MiB 比较，超大配置不会溢出后错误通过。检测回填默认地址与实际架构，保留用户后续修改；迟到响应不覆盖已切回的远程目标，不兼容镜像明确提示 |

复用现有 Docker SDK/CLI 配置和官方 k3d CLI，不新增依赖。官方 k3d 库会与应用 client-go 及 Kubernetes 依赖版本耦合，本次沿用已有独立 CLI 契约；连接、RBAC、任务锁与资源归属规则仍由项目维护。

后端完整 K3s 回归、相关 HTTP 权限用例、本地/Docker 边界 race 检查、127 项相关前端测试及生产构建通过。测试使用隔离 CLI、HTTP 与 Kubernetes 桩；浏览器夹具拦截全部外部请求。不把夹具成功称为真实集群安装验收。
