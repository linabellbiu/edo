# 镜像构建高级配置验收

本批按用户最新要求恢复单个 Docker target，镜像名称与 target 移入高级配置，镜像 Tag 保留常规配置。此前删除 target 的验收为历史记录，本批规则取代其新运行行为。

复用现有 Docker CLI 的 `--target` 参数、已有持久字段及构建执行器，不新增通用解析器或依赖。阶段名校验属于产品输入边界，不解析或修改业务 Dockerfile；阶段实际存在性由 Docker 构建确认。

| ID | 角色及前提 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| BTA-01 | 可编辑流水线，内联镜像构建 | 打开常规和高级页签 | 常规保留 Tag，高级显示可选镜像名称和单个 target | 通过 |
| BTA-02 | 同上 | target 填 runtime，保存后重开 | 参数保留；留空构建最终阶段 | 通过 |
| BTA-03 | 同上 | 填逗号、空白、换行列表或超长阶段，切回常规再保存 | 输入处报错，保存被阻止，定位高级配置并保留草稿 | 通过 |
| BTA-04 | 有方案读取与修改权限，引用库方案 | 打开高级配置并点击修改 | target 只读，镜像名称仍按任务编辑，修改打开准确库方案 | 通过 |
| BTA-05 | 方案编辑者 | 独立方案展开高级配置，保存、重开、切换脚本 | target 保存回显，脚本不提交隐藏阶段 | 通过 |
| BTA-06 | 可查看任务 | 鼠标、键盘、点击问号 | 说明 target 选择 Dockerfile 命名阶段，留空使用最终阶段 | 通过 |
| BTA-07 | 构建服务与正常 HTTP 接口 | 创建和更新单阶段及非法列表 | 单阶段持久化，非法输入返回 400，不改变原方案 | 通过 |
| BTA-08 | 独立测试数据库，已创建运行快照 | 修改方案、生成下次运行、读取旧记录 | 已有快照冻结原阶段，下次采用新阶段，每个构建节点仍只有一项任务；旧无效列表阻止新运行且原数据不被改写 | 通过 |
| BTA-09 | 本地 EDO，原数据及依赖正常 | 只更新 API 与 Web | 本地新版本健康，数据库、Redis、NATS 和构建器不重启 | 更新后写入本机 receipts，独立记录 |

页面使用真实 Vue 与 Ant Design 组件和隔离内存接口，不触发业务流水线，不推送镜像或发布业务应用。HTTP、数据库快照和 Docker CLI 参数分别由对应集成或单元测试验证，不互相替代。

验证：前端全套 1806 项通过，Vue 类型检查及生产构建通过；流水线完整 Go 竞争检测通过，HTTP 构建方案创建/更新接口及 Docker buildx 参数定向竞争检测通过。真实页面验证了常规与高级分区、问号键盘聚焦、库方案只读和准确修改入口、独立方案 target 保存回显，以及内联非法列表阻止保存、修正后保存。未触发真实业务构建。
