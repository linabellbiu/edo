# 组织与部门双栏工作区

用户确认使用“左侧部门树＋右侧成员”。参考飞书官方的[部门管理](https://www.feishu.cn/hc/zh-CN/articles/360033588234)和[成员管理](https://www.feishu.cn/hc/zh-CN/articles/578016169187)公开文档及界面截图：部门树承担范围选择，所选范围的成员和资料在内容区展示；节点使用轻量添加和更多菜单。只借鉴布局及交互，不增加 EDO 没有的负责人、部门群、电话、邮箱、批量导入等功能，不使用参考站图片或品牌素材。

| ID | 角色与前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| ORG-DIR-01 | 有组织与部门查看权限，存在多级部门 | 切换公司、默认部门、下级部门，搜索、展开收起、刷新列表 | 默认部门置顶，选中态清晰；右侧资料和直属成员同步更新，路径可返回，刷新列表保留选择；树中不再混排成员或长说明 | 通过：本地实际组件页面与组件测试 |
| ORG-DIR-02 | 有公司修改和部门操作权限 | 使用节点加号及菜单新增、编辑和删除确认；取消公司编辑 | 上级名称准确，提交绑定对应 ID；保存后选中新部门；默认部门不可删除，原有确认保留；公司草稿取消不修改已显示资料 | 通过：内存数据新增及修改成功；默认部门菜单仅有编辑；删除确认后取消；公司草稿取消保持原资料 |
| ORG-DIR-03 | 有成员查看权限，或仅部门查看权限 | 成员姓名与账号搜索、分页、切换部门，模拟失败和撤权 | 成员目录完整分页；右侧只显示所选范围；正常、停用、空列表、无匹配、无权限与读取失败分别处理，不补造零人 | 通过：本地页面验证分页、搜索及各状态；撤权和迟到响应由组件测试覆盖 |
| ORG-DIR-04 | 桌面、窄屏、浅色与深色 | 查看双栏、长名称、键盘节点操作和表单 | 双栏与 Vben 风格一致；紧凑树节点无长线及按钮条，右侧列表列宽和层级清晰；窄屏转上下布局、仅表格内部滚动；权限操作可用键盘访问 | 通过：1440px 桌面、390px 窄屏及深色截图已查看；长名称不撑宽页面，键盘 Enter 可打开准确上级的新增抽屉 |

复用当前 Ant Design Vue Tree/Table、组织/部门接口及精简成员目录，不增加依赖或数据库修改。功能写入验收使用内存合成数据，线上只读核查。

## 本地验证

- `organizationFormsAcceptance`、`workspaceAccess`、`mutation-acknowledgement` 共 105 项通过；覆盖成员目录 200 条以上的真实分页请求方式、直属范围、身份失效、公司草稿、精确新增选择及原有保存失败语义。
- `npm run build --prefix web` 通过，包含 Vue/TypeScript 检查与生产资源构建。
- 浏览器夹具为 `web/tests/fixtures/organization-tree.html`。成员合成数据共 13 名，页面每页 10 条；公司第二页显示剩余 3 名，账号筛选后回到第一页；支付服务组的停用成员使用中性状态。
- 无成员权限与请求失败时，公司成员数为未知值，不显示零人；只读身份没有新增和编辑节点按钮。所有本地写入只修改夹具内存，没有创建或修改线上组织数据。
- 390px 页面与文档宽度均为 390px；成员表在自身容器内横向滚动，部门长名称在详情中换行。保留全站 Vben、侧栏及登录样式。
