# 配置管理与内置部署参数验收

用户确认配置独立管理，支持多种文本格式；部署优先复用内置 Docker、Compose。选择 ENV 后不要求自定义命令，额外选项通过部署参数配置。重启沿用容器原配置，重建沿用最近实际成功部署的冻结配置；未执行流水线时，编辑或移除参数不改变已有实例。

## 依赖选型

YAML 复用已有 yaml 2.9.1 和 CodeMirror。TOML 使用 smol-toml 1.9.1（BSD-3-Clause，无运行依赖）；审查已公开的旧版解析挂起修复，并回归不完整输入。INI 使用 npm 维护的 ini 7.0.0（ISC，无依赖），补充常见分节及 key=value 的行检查，因为解析器本身会容忍错误行；INI 方言差异仅作警告，不声称验证应用语义。JSON 使用 CodeMirror 官方 JSON 解析器（MIT）。未采用已归档的 legacy-modes；语言解析和编辑器依赖可以替换，配置原文和业务权限逻辑不依赖解析器输出。新增包适用项目容器 Node 24.16，当前本地 Node 25 会收到 ini 的版本范围警告，构建与测试实测通过。

本批只修改 EDO；未推送或部署，未操作业务容器。
