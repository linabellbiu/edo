# K3s 卸载结果页精简

默认只突出一次主机、卸载结果、总耗时和日志。任务编号与起止时间放入默认折叠的“任务详情”，其他卸载记录放入默认折叠的“卸载记录”，当前任务不重复列入历史。失败原因、结果未确认与进度读取失败继续直接显示。只调整前端展示，官方脚本、RBAC 和手动确认流程不变。

| ID | 前置与角色 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| UR-01 | 有卸载查看权限；已完成记录 | 打开卸载结果 | 状态、耗时和日志清晰；不重复主机、阶段、最近反馈或当前历史行 | 通过：隔离浏览器默认完成页，主机仅一次、无重复阶段与当前历史 |
| UR-02 | 同上；其他历史存在 | 用鼠标及键盘展开任务详情、历史并切换记录 | 可读取完整任务编号、时间和其他记录；关闭折叠不丢数据或列表关联 | 通过：键盘 Enter 展开任务详情、鼠标展开历史并切换，切换后详情恢复折叠 |
| UR-03 | 运行中或等待执行 | 查看进度、等待更新 | 真实阶段与总耗时继续更新；后台执行提示位于日志旁；完成后停止计时 | 通过：运行页显示真实阶段与连续计时，完成后冻结由前端回归覆盖 |
| UR-04 | 失败、结果未确认或轮询异常 | 打开对应任务 | 必要错误与保留锁提示直接可见，不藏在折叠区，刷新和确认限制保留 | 通过：失败和不明结果页面提示直接可见；轮询失败与刷新入口由原回归及代码复核覆盖 |
| UR-05 | 浅色、深色及窄屏 | 查看完成、失败和运行中状态 | 文字与状态可读，无横向溢出，折叠入口有键盘焦点 | 通过：浅色 1280px、浅色 390px、深色 390px，均无横向溢出 |

页面使用隔离前端夹具验收，不连接真实主机或执行卸载。

验证：`node --test web/tests/k3s-uninstall.test.mjs web/tests/k3s-progress.test.mjs` 32 项通过，`cd web && npm run build` 通过，`git diff --check` 通过。安装进度原有显示、卸载权限、精确确认、任务锁与轮询回归继续通过。

隔离页面：`web/tests/fixtures/k3s-uninstall.html?result=success&history=1`，支持 `result=failed|running|uncertain`、`theme=dark`。请求全部由内存适配器拦截，未执行真实卸载。
