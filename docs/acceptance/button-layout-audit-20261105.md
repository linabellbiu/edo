# 全站按钮图文布局检查

扫描 `web/src` 下 458 个 Ant Design Vue 按钮及 145 个原生按钮声明。普通 Ant 按钮默认 `inline-block`，其图标间距仅照顾组件库图标，直接插入的 Lucide SVG 不会自动对齐或留空。共用样式改为横向居中布局并补 6px 默认图文间距，同时去除内置图标及加载图标原有外边距的重复叠加；局部紧凑按钮继续使用已有间距和尺寸。

原生按钮中的导航、终端、资源选择、任务卡片等已有 flex / grid 布局，按各自信息结构保留。纯图标按钮不增加文字内边距，不将复杂选择卡片压成单行。

| ID | 角色与前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| BTN-ALL-01 | 查看页面及本机按钮夹具 | 检查工具栏、表格、抽屉及弹窗中的前置/后置图标、SVG 品牌图标、普通文字按钮 | 图标与文字垂直居中，图文有间距，无贴边或双倍间距 | 通过，12 个实际页面的可见图文按钮及弹窗、抽屉按钮均居中 |
| BTN-ALL-02 | 按钮夹具 | 检查 default / primary / link / text / danger、小/中/大号、纯图标、禁用、加载状态 | 图文居中，加载图标不叠加间距，纯图标保持原尺寸，焦点可见 | 通过，53 个样式样本；纯图标保持 24 / 32 / 40px，键盘焦点为 2px outline |
| BTN-ALL-03 | 上述页面及夹具 | 切换浅深色和窄屏 | 尺寸与间距正常，原有布局与操作入口保留 | 通过，1280px / 560px、浅深色、加载前后共 8 种显示条件，中心偏差最大 0.01px |

沿用项目现有 Ant Design Vue 和 CSS，不引入依赖；页面夹具使用本机模拟数据，不提交业务操作。

额外调整：域名厂商树“添加”和 Pod 详情按钮的 3px / 2px 图文间距均改为 6px；主机顶部按钮移除重复的对齐样式，复用共用规则并保留原内边距。表格紧凑按钮继续使用 4px 间距和原尺寸，纯图标表格按钮保持 30×28px。

实际页面样本包括主机、集群、环境、应用、代码仓库、个人凭据、流水线、构建方案、部署方案、发布计划、运行记录及日志。页面检查使用只读模拟接口，仅证明展示行为；未将所有隐藏表单和角色分支声称为逐一真实业务操作验收。

前端全量 1669 项测试通过，类型检查与生产构建通过。复现入口为开发服务中的 `/tests/fixtures/button-layout.html`，`?theme=dark` 可直接查看深色；夹具包含加载状态切换及真实弹窗、抽屉，不进入生产构建入口。
