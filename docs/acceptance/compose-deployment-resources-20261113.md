# EDO Compose 部署资源展示验收

修复流水线运行及发布计划中的“部署资源”抽屉未接入 Compose 服务的问题。复用现有部署运行状态接口、服务容器表、日志和终端组件，不新增依赖、数据库字段或执行工具；服务镜像来自准确部署对应的实际容器，不从上游构建或当前方案猜测。多服务记录不再用空的单镜像字段显示“未记录镜像”。

| ID | 角色与前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| CDR-01 | 部署可读；Compose 有多服务、多副本及已完成容器 | 流水线运行详情打开部署资源，刷新状态 | 展示真实项目名、服务、容器、镜像和状态；不以历史部署成功代替实时健康 | 通过（组件自动化） |
| CDR-02 | 有日志权限及独立 Exec 权限 | 选择准确容器查看日志或 Exec；模拟停止和重建 | 打开前复查原容器 ID 与运行时，停止容器可读日志且不能 Exec，不改连新副本 | 通过（组件自动化） |
| CDR-03 | 只读、撤权或切换项目/记录，读取仍未结束 | 打开、切换、关闭或使权限失效 | 缺权限有提示；请求取消，迟到响应不回填，已打开连接关闭 | 通过（组件自动化） |
| CDR-04 | 历史记录已被替代或运行接口失败 | 打开部署资源并重试 | 显示后端安全错误及刷新入口，不伪造服务、状态或镜像 | 通过（组件自动化） |

页面验收使用真实 Vue 组件和隔离合成接口：`web/tests/fixtures/compose-runtime.html?resources`。覆盖浅色、深色和窄屏，不连接实际业务 API，不执行真实部署、重启或容器操作。真实运行时与 WebSocket 复用已有实现，本轮不把合成页面验收称为实际容器联调或已发布。

定向组件与关联流程回归 43 条通过；前端类型检查和生产构建通过。已从运行列表的“详情 → 部署记录与回退”入口完成浅色、深色与 390px 窄屏检查；窄屏表格保持抽屉内独立横向滚动，整页宽度为 390px。已完成容器的 Exec 禁用，容器详情继续展示完整镜像与其他事实；本轮新入口仅提供查看、日志和 Exec，未新增运行控制。旧单服务 Compose 沿用该部署冻结的运行时身份。浏览器未记录脚本错误。
