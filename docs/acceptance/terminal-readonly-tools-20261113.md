# 只读容器终端工具卷

| 用例 | 角色及前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| TRT-01 | 有部署权限，新 Compose 运行 | 准备部署配置 | 补充项目隔离的只读工具卷，保留 rootfs 只读、用户、cap_drop、安全设置和业务挂载；显式关闭 init 或共享 PID 的服务不修改 | 通过：配置单测及真实 Compose 隔离部署 |
| TRT-02 | 同一配置再次准备，或保留历史运行 | 生成或解析快照 | 重复准备幂等；新快照启用工具卷，旧快照不改变 | 通过：配置及流水线快照回归 |
| TRT-03 | 工具目录冲突、外部卷、可写卷或驱动绑定宿主机 | 准备配置或打开终端 | 明确拒绝，不修改业务数据卷或宿主机目录 | 通过：保留 Compose 原有隔离校验，覆盖保留目录及卷归属、驱动与选项 |
| TRT-04 | 无 Exec 权限、准备期间撤权 | 打开终端、创建准备容器后或复制后撤权 | 禁止写入或停止后续执行，清理本次准备容器；失败审计不得记成功 | 通过：无授权、创建后撤权和复制后撤权回归 |
| TRT-05 | 真实本机 Docker，SSH 字节流，root / 非 root | 从生成的 Compose 部署只读测试容器，打开、收发、调整尺寸、关闭 | 工具卷可用，业务只读及安全设置保持，重启次数为 0；会话子代和未启动的准备容器均清理 | 通过：真实 arm64，root 与非 root 各一项；不代表公网目标验收 |
| TRT-06 | 工具复制损坏、准备容器身份变化、清理拒绝 | 准备工具 | 不执行、不登记安装成功，不强制删除身份变化的容器 | 通过：失败路径回归 |
| TRT-07 | 旧只读容器，没有工具卷 | 打开终端 | 不写只读根目录，提示重新部署，不自动重建；预装匹配摘要工具仍可复用 | 通过：边界单测；原业务目标需要用户重新部署，尚未恢复 |

测试复用官方 Compose 解析和 Moby API，没有添加宿主机 Shell、提权或后台常驻工具。真实用例仅创建随机名称、无网络、128 MiB、0.5 CPU 的 Alpine 容器，Compose 项目及卷均独立并在完成后清理。两个工具架构的摘要安装有单测，真实运行架构为本机 arm64。测试没有触发业务流水线、重推业务镜像、修改业务仓库或重建已有业务容器。
