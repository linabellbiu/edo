# K3s 卸载二次确认与 RBAC

卸载沿用独立项目权限 `kubernetes.k3s.uninstall` 和 `cluster.read`。从主机菜单进入后，先选择来源安装并预览目标，再阅读数据删除提示，手动输入完整的“我已确认卸载”，最后点击“确认卸载”。不会通过打开抽屉或预览自动提交。

| ID | 角色与前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| UCF-01 | 具备两个权限，有准确目标与有效计划 | 预览后检查目标、警告及输入框 | 主机、地址、角色、脚本、目录可核对；完整风险提示可见；输入框为空，按钮禁用 | 通过：隔离页面实际操作，初始输入为空；警告位于确认框正上方 |
| UCF-02 | 同上 | 输入旧口令、空白、短语、带空格或换行的确认语；再输入“我已确认卸载” | 不正确时前端不提交，后端拒绝且无任务/执行副作用；精确输入才可提交 | 通过：前端、HTTP 与业务层覆盖旧口令、短语、空格、换行及零宽字符；无效确认无任务或远程执行副作用 |
| UCF-03 | 缺少任一权限，或预览后被撤权 | 打开、预览或提交 | 前端不放行，接口和业务层拒绝，已有确认失效 | 通过：独立权限、项目隔离、个人拒绝、提交/后台撤权回归；无权限页面请求为零 |
| UCF-04 | 有效计划已手输完整确认语 | 返回、换来源/主机/项目、关闭重开、计划过期 | 旧计划或确认被清理，必须重新核对和手动输入 | 通过：前端来源/上下文/过期回归，以及后端计划归属、有效期与重复提交回归 |
| UCF-05 | 浅色、深色及窄屏的隔离前端页面 | 按正常流程操作至二次确认 | 风险提示完整可读，手动输入完整口令才解锁；无权限时不可操作 | 通过：隔离浏览器浅色、深色及 390px 窄屏操作；无横向溢出，完整风险提示可读 |

本批验证不执行真实主机卸载，不以模拟任务受理作为实际卸载成功。

验证命令：

- `node --test web/tests/k3s-uninstall.test.mjs`：22 项通过。
- `go test -race ./internal/k3s ./internal/httpapi ./internal/access -run 'Test(Uninstall|K3sUninstall)' -count=1 -timeout 180s`：三个包通过。
- `cd web && npm run build`：类型检查及生产构建通过。

隔离页面：`web/tests/fixtures/k3s-uninstall.html`，支持 `?theme=dark` 和 `?denied=1`，全部请求由内存适配器拦截。浏览器验证确认语发送为“我已确认卸载”，无权限时请求为零；没有连接真实主机。截图：`/tmp/edo-k3s-uninstall-confirmation-light.png`、`/tmp/edo-k3s-uninstall-confirmation-dark-narrow.png`。
