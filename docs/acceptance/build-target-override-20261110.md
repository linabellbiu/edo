# 流水线任务构建阶段覆盖验收

本批按用户最新要求，任务级 Docker target 可编辑，未配置时显示并沿用当前方案模板值，模板未填则为空。任务显式值具有最高优先级，包括空字符串：清空表示构建最终阶段。公共方案保持独立；本规则取代此前库方案 target 只读的约定。

复用已有 Docker CLI、单阶段校验、流水线 JSON 配置与不可变运行快照，无新增依赖或数据库列。缺失字段表示继承，字符串字段（含空字符串）表示任务覆盖；不改写公共构建方案，不执行业务仓库修改。

| ID | 角色与前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| BTO-01 | 可编辑任务，公共方案 target 为 runtime | 打开高级配置 | 输入框可编辑，实际值为 runtime | 通过 |
| BTO-02 | 同上，公共方案 target 为空 | 打开高级配置 | 实际值为空，不填入占位示例 | 通过 |
| BTO-03 | 可编辑任务，公共方案 target 为 runtime | 改为 builder 并保存重开 | 任务回显 builder，模板保持 runtime，执行快照使用 builder | 通过 |
| BTO-04 | 同上 | 清空、保存重开 | 任务明确保存空值，执行最终阶段，不能回退 runtime | 通过 |
| BTO-05 | 同上 | 未修改时更换模板；设置覆盖后再更换 | 未覆盖时沿用新模板；覆盖后继续使用任务值 | 通过 |
| BTO-06 | 内联构建或公共方案任务 | 填多个阶段后保存 | 前后端拒绝，保留草稿；修正后可保存 | 通过 |
| BTO-07 | 查看用户、可编辑用户 | 查看、修改 target；切换来源、保存和重开 | 查看用户不能修改，覆盖跟随当前任务，不请求写入公共方案 | 通过 |
| BTO-08 | 已创建运行快照 | 更改模板或任务覆盖 | 旧运行不变，新运行冻结最终生效值 | 通过 |
| BTO-09 | 可查看任务 | 悬停、键盘聚焦问号 | 说明 FROM … AS runtime、--target runtime、仅一个阶段及空值语义 | 通过 |

页面验收使用真实 Vue/Ant Design 组件及隔离内存接口；HTTP 和独立数据库测试验证实际保存与读取、覆盖及空值语义。构建执行参数复用既有测试，不触发真实业务流水线或镜像发布。公共权限规则复用已有通过的项目隔离和撤权用例。

验证：前端全套 1808 项通过；生产类型检查与构建通过；流水线完整 Go 竞争检测通过，任务覆盖正常 HTTP 接口及优先级/快照专项竞争检测通过。实际隔离页面确认库方案默认值可编辑、builder 保存回显、明确清空被保存、覆盖操作不请求写入公共方案。其他继承、权限、换方案和快照分支由对应状态与集成测试验证。未触发业务构建或部署。
