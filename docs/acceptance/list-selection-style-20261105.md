# 列表定位与选中样式检查

构建方案的蓝色竖线来自共用 `plan-list.css` 对 `.is-current` 第一列添加的 3px 内阴影，链接中的 `plan` 参数或查看制品都会触发定位状态。定位状态继续保留，改用整行浅色背景。

同时检查并移除应用、运行记录及分组、通用资源表格、计划详情区、主机分组及运行资源选择、预设分类、Kubernetes 版本 / Pod / 容器选择、流水线节点通知标题、系统日志条目的同类装饰竖条。状态标签、浅色选中背景、细分隔线和键盘焦点继续使用原有样式；权限覆盖中的允许 / 拒绝颜色不属于本次装饰竖条。

| ID | 角色与前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| SELECT-01 | 有查看权限；构建方案有数据 | 从带 `plan` 的链接定位方案，查看制品后返回列表；检查部署、应用和运行列表定位态 | 无蓝色竖条；当前项仍以浅色背景显示，链接和操作目标保持准确 | 通过，真实页面组件配合只读模拟接口；4 类列表定位项的内阴影均为 none |
| SELECT-02 | 通用列表、预设及 Kubernetes 选择面板有数据 | 切换选中项，查看普通、悬停、选中及键盘焦点状态 | 无同类竖条；选中与未选中可区分，键盘焦点仍可见 | 通过，仓库详情选中、预设分类、版本及 Pod、模板容器；键盘 Tab 焦点保留 2px outline |
| SELECT-03 | 两类共用表格 | 检查浅色、深色、窄屏、关闭详情后再打开 | 无竖条残留；布局、滚动及详情入口正常 | 通过，构建方案浅色及深色、制品抽屉关闭返回、560px 窗口和 Kubernetes 浅深色夹具 |

CSS 展示调整沿用现有 Vue 与 Ant Design Vue 样式，不引入依赖或修改业务、权限与资源定位逻辑。隔离页面使用模拟数据，不冒充真实业务资源验收。

执行记录：前端全量 1667 项测试通过，类型检查和生产构建通过。构建方案 560px 窗口下页面宽度为 560px，表格自身保留横向滚动；当前项没有内阴影。系统日志的信息 / 错误样本均无左边条，原等级标签继续显示。主机分组、旧运行资源选择与通知标题通过源码统一检查，不将未进入的界面记为真实页面验收。
