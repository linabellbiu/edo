# 集群连接状态与部署失败提示验收

日期：2026-11-16

## 现场原因

集群列表只显示 `is_active` 对应的“已启用”，没有反映当前 EDO 后端能否访问 Kubernetes API。启用、网络连通和操作权限是不同的状态。离开内网后，其他主机的 SSH 穿透可用，不代表 EDO 到已保存的 Kubernetes API 地址也可达。

本次失败运行的内网 Compose 分支读取用户目录超时，Kubernetes 分支读取节点架构时连接被拒绝；穿透 Compose 分支成功。并行分支隔离已经生效，但任务资源冻结把不同原因覆盖成了同一句配置或权限不可用。
