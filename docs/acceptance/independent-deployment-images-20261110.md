# 部署镜像独立配置验收

> 最新规则：`${EDO_IMAGE_TAG}` 只表示 Tag，部署不需要关联构建任务。版本自动使用 Git Tag 或 12 位短 Commit SHA；镜像名称由用户配置。详见[镜像 Tag 语义修正验收](../image-tag-only-acceptance.md)。历史运行继续按原快照执行。

用户确认删除自动匹配，部署只按用户配置执行。新 Compose 运行不自动绑定上游镜像制品，不因为与上游镜像名称、Tag 或仓库不同而阻断。当前选定仓库仅用于认证与拉取用户在 Compose 中填写的镜像；明确选择的外部镜像和文件来源继续按配置使用。新版 Docker 部署必须明确选择镜像与 Tag，部署脚本和文件来源不再自动继承父运行的上一份镜像；仍保留用户明确选择的构建来源。Kubernetes 既有的上游制品选择流程未调整。

| ID | 操作与预期 | 结果 |
| --- | --- | --- |
| IDC-01 | 上游产出 A，Compose 使用 B；新快照不产生自动镜像绑定 | 通过：真实隔离数据库保存方案、流水线并创建运行快照 |
| IDC-02 | 无上游构建、上游为文件构建，Compose 仍能独立配置 | 通过：三种前置构建组合创建运行 |
| IDC-03 | 从用户选择的仓库读取 Compose 实际镜像，固定实际 Digest；不向其他仓库传送认证 | 通过：本机 HTTP OCI 测试仓库解析 Digest；其他仓库与未选择服务保持原配置 |
| IDC-04 | 页面不再根据上游自动预填或写入部署仓库 | 通过：组件状态、显式选择、重开回显、项目切换与权限回归 |
| IDC-05 | 显式配置文件、上游文件来源和项目隔离继续生效 | 通过：来源保留测试、跨项目仓库拒绝与完整流水线回归 |
| IDC-06 | 已启动的旧运行仍读取原有不可变快照 | 通过：旧快照缺省标记、原制品来源与原 Compose 匹配回归 |
| IDC-07 | 显式镜像来源创建运行后 Tag 漂移，部署继续使用本次已冻结 Digest | 通过：再次解析不查询仓库，也不覆盖冻结值 |
| IDC-08 | 上游镜像仓库和部署仓库不同，Docker/自定义部署不继承未选择的父运行镜像 | 通过：来源收集、并行执行来源和实际执行上下文加载测试 |
| IDC-09 | 取消绑定后，镜像构建仍覆盖后续部署主机架构；文件构建不被当作镜像来源 | 通过：amd64/arm64 构建平台回归 |
| IDC-10 | Tag 上下文只读取本次运行、当前应用与项目的前序阶段，不覆盖自定义变量 | 通过：不同仓库、同阶段任务、跨项目与不同 Tag 回归 |
| IDC-11 | 镜像插值出错时记录操作上下文，诊断与对外错误不泄露密钥值 | 通过：日志脱敏回归 |

`EDO_IMAGE_TAG` 在前序镜像产物具有唯一 Tag 时继续提供，供用户主动引用；不同 Tag 不猜测、不以此校验镜像关系。仍可使用用户变量或固定 Tag。未引用内置镜像 Tag 时不查询构建制品。内置流水线上下文只用于 Compose 插值，不自动注入每个容器。未从构建产物推导部署镜像。

复用已安装的 Compose 官方 compose-go 模板解析器处理 image 插值（包含默认值与必填语法），复用 regclient 从用户选定仓库读取实际 Digest；未增加第三方依赖。

验证：流水线完整 `go test -race` 通过（54.502 秒），新增场景另做定向竞争检测；流水线、构建方案及部署相关 HTTP 接口竞争检测通过（25.553 秒）；前端全量 1792 项、部署组件定向 16 项及 Web 生产构建通过。本机 Node 24.16 的全量测试关闭实验性 Web Storage（`node --no-experimental-webstorage --test tests/*.test.mjs`），避免 Node 的空 localStorage 对象干扰浏览器测试替身，全部用例及断言保留。本批未更新本地或远程运行实例，未做真实浏览器页面保存、真实 Docker 拉取及业务部署验收；HTTP OCI 仓库为隔离测试服务。
