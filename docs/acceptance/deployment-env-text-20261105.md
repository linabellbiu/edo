# 部署 env 文本验收

| ID | 角色与前置 | 操作 | 预期 |
| --- | --- | --- | --- |
| ENV-01 | 当前项目变量可操作用户 | 默认新增 env 文本，输入多行、长行，保存并编辑 | 默认 environment 模式；仅按物理行分割；水平滚动；原有逐条添加可切换 |
| ENV-02 | 同一应用的两个环境 | 保存同名配置并分别引用 | 仅解析当前环境；运行固定版本；密钥不回显 |
| ENV-03 | Compose 部署可操作用户 | 引用 env 文本，YAML 中有/无 environment | 自动合并所有服务的 environment，同名以本次配置为准，无关字段保留 |
| ENV-04 | Compose 部署可操作用户 | 引用命名 .prod.env 的文件配置 | 自动创建受限文件并添加 env_file；原 env_file 保留；正文不进入快照及发布记录 |
| ENV-05 | 当前项目变量可操作用户 | 输入重复名称、缺少等号、非法文件名或系统变量 | 明确失败且不保存；错误不包含输入值 |
| ENV-06 | 已有逐条变量使用方 | 修改、保留密钥、切项目及撤权 | 原流程可用；草稿清空；旧授权不能保存或执行 |

## 执行结果

- ENV-01：通过。使用实际 `DeliveryVariablesView` 的合成接口夹具，默认文本模式及保存正常。桌面文本框实际 `wrap=off`，宽 570、内容宽 2683；390px 窄屏文本框宽 324、内容宽 1587，页面宽仍为 390。长行仅在文本框中横向滚动。浅色、深色、窄屏及逐条模式已检查。
- ENV-02：通过本地持久化验证。SQLite 与独立 MySQL 8.4 均覆盖新文本/文件配置的加密、冻结版本及撤销；已有同名变量的应用/环境优先级回归通过。没有改表或迁移。
- ENV-03：部分通过。本地执行器通过。真实 Docker Compose 5.5.1 在两个合成服务中确认 environment 自动合并、覆盖和空值，保留字面美元符号、等号、引号和尾部反斜杠。尚未通过真实 EDO 页面启动完整远程流水线，不把 CLI 验证称为服务器发布验收。
- ENV-04：部分通过。本地执行器通过。真实多镜像配置生成与单镜像本机 CLI、远程 Shell 载荷的本机执行均验证命名 env_file 注入；文件权限 0600，单镜像临时文件随命令清理。单元测试确认正文不进入生成的配置/发布脚本，发布变量仍复用版本和权限恢复。远程 SSH 认证与完整后台发布链路未测。
- ENV-05：通过。正常 HTTP 路由请求及后端校验覆盖重复键、缺少等号、系统变量、非法文件名；错误只含安全行号，无输入值，无效请求不落库。
- ENV-06：通过。前端相关 28 项回归通过，Go 变量、流水线、部署和 Docker 执行包全量竞争检测通过，变量正常接口及项目权限回归通过。原有逐条添加已在真实浏览器中保存合成变量，切项目、撤权、保留未替换密钥的原有用例继续通过。

首次真实文件测试发现单引号编码遇到尾部反斜杠时被 Compose 判为未闭合引号，保留该失败记录；改为官方 `env_file.format: raw` 后，相关真实容器测试重新通过。该模式要求 Compose 2.30 或更新版本，不自制另一套 dotenv 引号解释器。

页面夹具只使用合成接口与合成数据；正常 HTTP 测试使用独立真实数据库；外部执行使用独立临时 Compose 项目。测试项目、容器和独立 MySQL 已清理，原有本机服务继续运行。本次不包含服务器部署。
