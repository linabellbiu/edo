# 部署 env 文本验收

| ID | 角色与前置 | 操作 | 预期 |
| --- | --- | --- | --- |
| ENV-01 | 当前项目变量可操作用户 | 默认新增 env 文本，输入多行、长行，保存并编辑 | 默认 environment 模式；仅按物理行分割；水平滚动；原有逐条添加可切换 |
| ENV-02 | 同一应用的两个环境 | 保存同名配置并分别引用 | 仅解析当前环境；运行固定版本；密钥不回显 |
| ENV-03 | Compose 部署可操作用户 | 引用 env 文本，YAML 中有/无 environment | 自动合并所有服务的 environment，同名以本次配置为准，无关字段保留 |
| ENV-04 | Compose 部署可操作用户 | 引用命名 .prod.env 的文件配置 | 自动创建受限文件并添加 env_file；原 env_file 保留；正文不进入快照及发布记录 |
| ENV-05 | 当前项目变量可操作用户 | 输入重复名称、缺少等号、非法文件名或系统变量 | 明确失败且不保存；错误不包含输入值 |
| ENV-06 | 已有逐条变量使用方 | 修改、保留密钥、切项目及撤权 | 原流程可用；草稿清空；旧授权不能保存或执行 |
