# K3s 直接执行官方卸载脚本

用户明确要求安装、卸载直接复用官方脚本，安装后的挂载和 K3s 操作交给用户。原有卸载预览对 Pod 临时卷、CNI 和系统服务的额外限制违背此边界，本批删除这些检查，未新增替代清理器。

| ID | 角色与前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| OUN-01 | 有独立卸载权限，准确来源及主机 | 预览、手动确认后提交 | 保留 RBAC、项目隔离、准确脚本目标、确认语及重复提交保护；后台只原样调用所选官方脚本 | 通过：业务与 HTTP 定向竞争检测；前端 22 项回归仍通过 |
| OUN-02 | 正常 Pod 挂载、CNI、Docker、代理环境或用户改过 K3s 配置 | 预览及执行受控官方脚本夹具 | EDO 不探测或处理挂载/网络/服务，不因这些资源阻断；不注入旧计划的环境或参数 | 通过：受控 shell 夹具覆盖 Pod/CNI/用户配置/env/drop-in/OpenRC；命令陷阱确认 EDO 不调用挂载、网络、服务或删除工具 |
| OUN-03 | 脚本文件非 root、符号链接、权限不安全，或确认后文件变化 | 预览或提交 | 文件目标与变更核验仍阻断，不能换脚本或换主机执行 | 通过：非 root、权限、符号链接、安装锁和脚本替换的负向覆盖保留 |
| OUN-04 | 官方脚本非零退出、中断或结果未确认 | 后台执行 | 保留失败、锁和日志，不自动补救、重试或伪报成功 | 通过：官方非零退出、不明结果锁及撤权回归保留 |
| OUN-05 | 官方脚本成功退出 | 核对结果 | 仅核对准确目标卸载脚本已移除；不自行删除残留或要求无关进程、服务和目录消失 | 通过：只观察准确目标脚本消失，保留其他文件、数据与锁的正向测试 |

本批不对真实主机执行卸载，不停止 K3s、不删除 Pod、不改挂载或网络。真实卸载仍需用户在页面手动输入“我已确认卸载”并点击确认。

验证：`go test -race ./internal/k3s ./internal/httpapi -run 'Test(Uninstall|K3sUninstall)' -count=1 -timeout 180s` 两个包通过；`node --test web/tests/k3s-uninstall.test.mjs` 22 项通过；`git diff --check` 通过。

官方依据：[K3s 卸载说明](https://docs.k3s.io/zh/installation/uninstall)，直接执行安装器在目标主机生成的 Server/Agent 卸载脚本。
