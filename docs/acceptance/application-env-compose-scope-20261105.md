# 应用环境配置与 Compose 服务范围

| ID | 角色、前置 | 操作 | 预期 |
| --- | --- | --- | --- |
| APP-ENV-01 | 有变量权限的项目成员，应用存在测试/生产环境 | 从应用详情进入环境配置，选择环境并保存文本或逐条变量 | 项目、应用固定；按环境隔离；普通文本无需起引用名；自动关联对应部署；保存不发布 |
| APP-ENV-02 | 同一应用已有密钥和共享变量 | 编辑、保留密钥、选择共享引用，切项目或撤权 | 密钥不回显，未替换值保留；共享变量明确引用；无越权或草稿残留 |
| APP-ENV-03 | 相同应用的两个环境与已创建运行 | 更新某环境配置后创建运行 | 只作用于指定应用/环境，已有运行快照不变，后台重新检查权限与配置版本 |
| CMP-SCOPE-01 | Compose 有多个服务 | 留空启动服务或选择部分服务 | 留空不向 up 追加服务名；选择后仅追加已选服务；官方依赖语义保留 |
| CMP-SCOPE-02 | 前序多个镜像构建，部分共用镜像 | 保存部署任务并执行 | 无逐行上游选择；按完整镜像引用自动匹配，摘要与所属运行继续检查；歧义或无匹配明确失败 |
| CMP-SCOPE-03 | 没有上游构建的固定镜像 Compose | 执行部署任务 | 使用 Compose 配置的镜像执行；不伪造制品或要求空构建任务 |
| CMP-SCOPE-04 | 选定服务部署失败，有其他运行中服务 | 检查失败恢复范围 | 恢复仅限本次范围及官方依赖，不对未选择服务执行 up，不执行 down 或删除卷 |

## Compose 执行结果

- CMP-SCOPE-01：通过。独立本机 Docker 项目运行实际 EDO 生成脚本，留空启动 api、db、worker；选 api 后 api 与依赖 db 更新，worker 容器 ID 保持。
- CMP-SCOPE-02：后端与前端组件测试通过。覆盖完整仓库路径、共用镜像、歧义拒绝、已有制品身份检查；真实远程流水线未执行。
- CMP-SCOPE-03：真实 Docker 脚本通过，使用 Compose 固定 alpine:3.22，无上游构建。另以真实测试数据库验证无构建流水线正常创建部署任务，不要求或借用其他制品。
- CMP-SCOPE-04：脚本测试通过，正常 up 与恢复 up 仅追加已选服务；真实失败恢复未补跑，已有模拟失败测试通过。
- 前端类型检查、生产构建与 Compose 配置组件用例通过。真实组件页面直接列出 api、worker，多选 api 后正确显示，无逐行上游构建控件。

## 应用环境配置结果

- APP-ENV-01：通过。本地真实应用列表 → 应用详情 → 环境配置，默认 environment 文本无需引用名；切换到测试环境保存 `.test.env`，通用环境单独保存文本与逐条 MODE。文本为 `wrap=off`、`white-space: pre`，超长行横向滚动；合成接口只保存配置，不发起发布。后台用独立数据库验证自动配置进入部署运行快照，任务无须填写 variable_names。
- APP-ENV-02：通过。真实组件页面验证加密标记、编辑不回显与默认保留密钥；前端组件回归覆盖项目/应用/环境切换、撤权、403 清理及取消迟到请求。项目共享变量仍由任务明确引用，自动配置不要求重复选择；已有显式引用保持可编辑。
- APP-ENV-03：通过。真实数据库测试覆盖应用及环境隔离、共享显式引用、旧变量不自动启用、版本更新后旧快照不变、停用后执行阻断；流水线测试验证自动配置不注入构建任务及撤销执行权限后的阻断。
- SQLite、PostgreSQL 18、MySQL 8.4 在独立测试库中分别通过初建、字段升级、UUID/自增 ID 保留、旧变量默认不开启自动注入及升级后继续写入。
- 后端 cicd、pipeline 完整竞争检测通过；deployment 完整回归与竞争检测通过；HTTP API 完整回归通过。前端相关 35 个用例、类型检查和生产构建通过。
- 页面以合成 API 驱动实际 DevOpsView、DeliveryVariablesView、ComposeTaskFields，分别检查浅色桌面和 390px 深色窄屏。没有执行线上业务流水线，也没有推送或部署本次改动。

## 使用入口

应用列表点击应用名称 → 环境配置（变量 / .env）→ 选择环境 → 添加配置。保存的新配置自动用于该应用对应环境的后续部署；已有手工变量在应用入口编辑保存后才开启自动使用。项目共享变量继续在项目变量页管理，由任务显式引用。

验收夹具：`web/tests/fixtures/application-env-scope.html`，使用合成数据，不连接业务 API。无需新增第三方包，继续复用现有加密修订、YAML 库与官方 Compose CLI。

页面、接口、持久化与真实 Compose 执行分别记录，不互相替代。
