# EDO K3s 主机回填与国内来源默认值

| ID | 角色与前置 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- | --- |
| KDS-01 | 集群创建者，有可选 SSH 主机 | 从控制平面或工作节点任一入口选择同一台主机 | 两侧回显相同主机；检测和计划只提交一个 Server，不重复提交 Agent | 通过（定向组件回归） |
| KDS-02 | 原生创建草稿，多台主机 | 增加 Worker、替换主机、清空，再切换原生/k3d | 其他主机保留独立 Agent 角色；范围准确、去重，旧检测失效，模式草稿隔离 | 通过（定向组件回归） |
| KDS-03 | 自定义安装明确设置或覆盖 disable-agent | 选择控制平面与独立 Worker，再切回默认安装 | 自定义保留纯控制平面；默认恢复同机 Worker，不修改安装脚本 | 通过（定向组件回归） |
| KDS-04 | 新建或重新打开原生表单 | 查看默认来源，改选官方/自定义，执行只读检测 | 默认两个国内源，实际请求明确携带所选来源；修改使旧报告和计划失效 | 通过（定向组件回归） |
| KDS-05 | 已有集群的 Master/Worker 加入、历史计划 | 打开添加节点或查看任务 | 国内下载默认值不改变目标集群镜像仓库，不改写历史任务 | 通过（定向组件回归） |

复用现有 Vue/TreeSelect、YAML 解析包和 K3s 安装接口，不增加依赖、持久化字段或新安装执行路径。页面验收使用 `web/tests/fixtures/k3s-preflight.html` 的真实抽屉与内存适配器，拒绝计划和安装写入，不连接实际宿主机、Docker 或 Kubernetes 集群。

验证结果：本次源码独立副本执行 100 条定向回归全部通过，类型检查及生产构建通过。真实抽屉中已逐向选择和取消主机，双侧名称一致；只读检测请求 1 次、计划和安装写请求均为 0。浅色、深色及 390px 窄屏可用，稳定后的抽屉宽度 374px、整页宽度 390px，无浏览器脚本错误。工作节点、控制平面和来源变化继续使旧检测失效。

单机使用现有 K3s Server 自带 Agent 的后端流程；测试确认请求中只有 `server_host_id`，同机不进入 `agent_host_ids`，多主机仍明确发送其余 Agent。未修改后端默认值、安装器、历史计划或实际集群，未进行真实原生安装或发布运行实例。共享工作区同期的数据库选择修改未纳入本次验收与提交。
