## 自动回填范围纠正

| ID | 前置与操作 | 预期 | 结果 |
| --- | --- | --- | --- |
| KDS-06 | 先选 A 得到 A/A，再手动把 Worker 改为 B；继续修改控制平面、清空 Worker 或切换模式 | 已填的另一侧不变；A/B 原样进入请求，清空不连带删除；再次选择仅补空值 | 通过（103 条定向回归及双主机真实组件页面） |

回填只发生在选择事件中，不再将控制平面持续插入 Worker 列表，也不根据 Worker 选择持续替换控制平面。Worker 草稿独立保存；发给接口时仍排除与 Server 相同的主机，避免重复安装。

纠正后的页面验收在临时独立副本中追加两台合成主机：先由控制平面 B 自动补齐 B，再将 Worker 改为 A，控制平面仍为 B，收起下拉后继续保留 B/A；对应 A/A → A/B 顺序及另一方向由组件回归覆盖。页面计划、安装及检测请求均为 0，无浏览器脚本错误，类型检查和生产构建通过。仅更新表单回填规则，未进行实际安装或发布。
