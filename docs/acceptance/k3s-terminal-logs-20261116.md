# K3s 安装执行日志验收

日期：2026-11-16。

安装日志从 EDO 合成阶段说明改为经脱敏的实际终端输出。阶段、任务状态、权限、确认及官方脚本保持原有边界。

| 范围 | 结果与证据 |
| --- | --- |
| 原生安装 | SSH 标准输出与错误按独立流组行；保存官方安装器输出，并只读跟随准确 K3s 服务的 journal。没有 journalctl 时保留安装器输出，不安装额外依赖 |
| k3d 创建 | 使用官方 `--verbose` 输出 Docker 分层拉取进度，不额外执行 docker pull。启动日志先核对安装与集群标签，再按不可变容器 ID 读取；失败时尝试有界只读快照，正常等待期间跟随日志，阶段完成取消并等待观察器退出 |
| 安装前检测 | 实际 curl 命令参数、stderr 和退出码通过编码反馈帧返回；日志不能伪装成阶段控制帧。报告可展开查看，保留明确失败项 |
| 安全与恢复 | 屏蔽已知输入凭据、生成令牌、认证字段、URL 认证信息、私钥和多行认证内容。支持分块、回车进度及无换行尾部；失败、取消及窗口关闭后保留已收集日志 |
| 容量与性能 | 每 500 毫秒批量写入，保留最近 2 MiB 完整行，单行超过 32 KiB 省略。100 行输出回归验证写入次数不随行数增加；阶段心跳不再混入安装终端日志 |
| 界面 | 纯文本显示，不执行 HTML/ANSI 控制内容；默认跟随最新输出，手动上滚保持阅读位置，“查看最新”恢复跟随。检测日志桌面和 390px 窄屏无横向溢出 |

验证：K3s 模块完整回归、相关 HTTP/RBAC 回归、日志与安装并发 race 检查、120 项相关前端测试及生产构建通过。浏览器使用明确标注的隔离夹具，检测场景只有一条模拟检测请求，没有计划或安装写请求；安装场景所有响应均来自内存模拟，没有真实主机操作。

本次没有执行真实 K3s/k3d 安装、卸载或主机修复；真实环境的输出与进度将在用户下一次从正常入口安装时采集，不能补造旧任务已丢弃的终端输出。以上测试不替代真实集群安装验收。
