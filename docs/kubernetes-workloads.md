# EDO 工作负载交互

工作负载参考用户指定的 Kuboard 页面（https://super-k3s.mxgent.cn/home/index）组织列表和关联浏览，保留 EDO 的项目权限、左侧范围选择和右侧详情抽屉。不复制参考站的业务配置、凭据或危险操作。

## 使用方式

- 六类已有资源共用范围选择、名称/镜像搜索、标签与状态筛选、排序及分页：Deployment、StatefulSet、DaemonSet、Job、CronJob、Pod。
- 刷新保留当前已加载的资源窗口；切换资源和浏览器返回恢复筛选、页码及加载深度，避免继续加载后的结果突然缩回第一页。
- 列表分别展示对应的就绪、更新、可用、调度、任务和容器字段。缺失状态不补零，缩容至零不标绿。副本、重启和任务数量按数值排序。
- 行尾保留详情与 Pod/日志入口，工作负载编辑、重启、扩缩容和删除等按权限放在更多菜单中；详情抽屉仍提供常用操作和确认。
- 在同一个抽屉内查看历史版本、关联 Pod、容器状态及配置/存储引用，返回后保留原资源上下文。环境变量只展示来源，不额外复制直接设置的值。
- 普通、Init 和临时容器可选择查看日志；终端仅对已授权且实际处于运行状态的普通或临时容器开放。没有创建调试容器、任意宿主机命令或文件浏览能力。
- 表单按基本信息、容器、Pod、调度与身份、任务或更新策略分区；未编辑的高级字段保留。离开普通表单和 YAML 编辑时都检查未保存草稿。

## 保存与兼容性

编辑表单打开前先读取最新工作负载，校验名称、命名空间与 UID，避免快速重开时复制旧列表行。保存时再次读取最新资源并校验 UID 和配置快照，再进行服务端 Strict dry-run；通过后才提交同一份配置。创建使用独立的 `POST /kubernetes/clusters/:id/resources/:resource/:name/validate-create` 校验入口，沿用对应创建权限，强制 Kubernetes `DryRunAll`，不持久化资源。校验失败保留当前表单与确认上下文；旧响应不能覆盖新资源的状态。

资源类型、原创建/更新接口、权限码及数据库结构均不改变。新校验入口不会占用名为 `validate` 的合法资源创建路径。本次不新增自动伸缩资源类型、回滚操作、Pod 调试容器或批量删除，也不修改真实集群资源。

## 验收边界

单元和脚本测试用于验证转换、取消、草稿及权限分支；真实 EDO API 接本地 TLS Kubernetes 夹具用于浏览器交互回归。夹具不等于真实 Kubernetes 调度、准入、RBAC、日志传输或 Exec 验收。线上发布及真实集群操作需另行明确执行，不能以本地构建或夹具成功代替。
