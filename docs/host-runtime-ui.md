# EDO 主机与运行资源

## 列表与抽屉

- 主机列表展示连接信息、系统基础资源、分组、能力及关联集群。Docker 图标是具备名称与键盘焦点的按钮，直接打开对应运行时，默认筛选运行中的容器。
- 抽屉使用单一工具栏、状态筛选、搜索和紧凑资源表格。单运行时直接展示列表，多运行时才显示选择入口；保留停止容器的日志查看，但仅运行中的容器可打开终端。
- 关闭抽屉保留主机列表筛选；失效的主机或运行时不自动替换成另一操作目标。用户、项目、部门或权限变化会清理旧结果，并取消未完成请求。
- 视觉调整仅作用于主机页及运行资源抽屉，使用现有 Vue、Ant Design Vue 和 Lucide；不修改登录页、全站主题或侧栏。

## 系统资源口径与接口

`GET /api/v1/hosts/:id/resources` 沿用主机查看权限与项目隔离，响应以 `resources` 包装。返回逻辑 CPU 数量、可见系统总内存、根文件系统总容量、操作系统及采集时间，未知数值为 `null`，不可用状态不能冒充零。

本地主机复用已有 `gopsutil/v4` 获取 EDO 当前运行环境可见的数据。远程主机复用已有 SSH 凭据解密与固定指纹连接，只执行内置、只读、无需 sudo 的采集协议。接口不接受用户命令、路径或脚本，不读取 Docker Info 代替宿主系统；虚拟机、容器或系统命名空间中的观测结果不宣称为物理宿主机资源，根文件系统容量也不代表所有物理磁盘容量之和。

前端只为当前分页呈现的主机按需读取，普通状态轮询不重新采集容量。成功结果缓存 60 秒，不可用结果缓存 10 秒；缓存包含项目及主机连接身份，最多 256 项。同目标共享在途请求，不同目标最多 64 个排队、4 个实际采集，总超时 10 秒覆盖等待与采集。

本次不引入新的采集、SSH 或缓存依赖。已复用项目中的 `gopsutil/v4` 与 `sshclient`；评估过已有 `singleflight`，它本身不提供不同目标的队列上限及请求取消规则，因此使用仅限此接口的有界在途表与 channel 槽位。该结构不是通用缓存框架，身份、容量空值、缓存复制与并发边界由定向竞争测试维护。

## 本地验收

本地预览：`/tests/fixtures/hosts-workspace.html`。夹具挂载真实生产组件，但仅使用内存测试数据，拒绝未登记请求与所有写请求；不会登录、迁移或修改本地和服务器数据库。它用于视觉及交互验收，不代表真实 SSH、Docker 或线上发布验收。

回归覆盖资源协议、固定主机指纹、超时与取消、有界并发、缓存隔离、权限拒绝及跨项目读取；前端覆盖直接入口、运行状态筛选、旧响应丢弃、过期行操作拒绝、停止容器日志和终端权限。浅色、深色与窄屏分别检查。
