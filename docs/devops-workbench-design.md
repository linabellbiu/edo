# DevOps 工作区骨架（应用首页起）

本文件记录 EDO DevOps 主线页面（应用、代码仓库、构建方案、镜像仓库、发布计划、流水线方案、主机与集群）向 Kubernetes 工作区同一套骨架靠拢的规则与进度。已落地的部分：应用列表。

## 1. 骨架

```
PageToolbar（说明 + 自动更新 + 刷新 + 主操作）
└─ 工具栏卡（搜索 + 筛选 chips）
└─ 表格卡（表头 / 行 / 操作列 / 分页）
```

- 页面说明、刷新和主操作归 PageToolbar，不在筛选区重复。
- 工具栏与表格各自独立成卡：12px 圆角、1px 冷灰边、白底；卡片间距 12px。
- 分页留在表格卡内部右下角，与表体用留白分隔，不单独再套一层。

## 2. 令牌（沿用全站与 K8s 工作区）

| 项 | 值 |
| --- | --- |
| 卡片圆角 | 12px |
| 控件圆角 | 8px |
| 表头 | 40px，12px / 600，冷灰底（primary 5% 混白） |
| 数据行 | 64px（应用名为两行：名称 + 描述） |
| 悬停 | primary 5% 混底 |
| 主操作 | 品牌蓝实底；行内操作为描边 28px 高 |
| 状态 | 成功绿 / 进行中蓝 / 警告琥珀 / 失败红，圆点 + 文字 |

## 3. 已落地：应用列表

- 筛选区从页面底色上浮为一张工具栏卡，搜索框 32px、筛选 chips 8px 圆角。
- 表头由 14px 行内文字改为 40px 冷灰表头，字号 12px/600。
- 数据行高度 68 → 64px，保持名称/描述两行可读；补悬停底色。
- 行内「检查更新」等按钮统一 28px 高、8px 圆角。
- 分页内嵌表格卡，去掉独立外边距。

预览：开发服务器打开 `/tests/fixtures/devops-applications.html`（合成数据，拦截全部真实接口与写操作）。
