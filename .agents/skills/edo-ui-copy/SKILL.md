# EDO 界面文案检查

1. 对照 `web/src/router/navigation.ts`、页面页签、抽屉标题和内容区。页面名称已经由侧栏、顶栏或页签表达时，删掉内容区重复的标题和同义说明。侧栏分组和子项同名时，按分组包含的功能命名，保持入口及导航层级清晰。
2. `PageToolbar` 用于页面操作和真实摘要。`summary` 可呈现数据数量或有独立意义的范围。删掉仅复述按钮、字段或页面用途的说明，并去除由这些文案撑出的空行。
3. 有独立意义的子区块名称、资源名称、数量和用户填写的说明继续显示。把权限、状态、错误、输入限制和操作影响放在对应控件或确认步骤旁。保留图标按钮的可访问名称、原操作入口和权限判断。
4. 检查全站共用工具栏及同类模板，并核对中英文文案。浏览器验收确认受影响的入口、操作位置和窄屏换行。

组织页顶部的「组织与部门」已由导航表达。内容区从「组织架构」和当前部门开始，刷新放在组织架构旁。
